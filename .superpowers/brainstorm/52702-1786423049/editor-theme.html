A · 自适应宿主主题（推荐）

保留 Crepe 的交互与布局，用项目 CSS tokens 重写颜色、圆角、阴影和焦点态。暗色与浅色入口自动适配，品牌一致性最好。

项目说明

所有场景都使用官方 Frame 的浅色编辑纸张。

稳定、统一、接近演示

B · 官方 Frame 原样主题

最接近 Playground，接入速度最快；但在暗色工作台里会形成明显的白色“纸张”，与现有产品外观割裂。

项目说明

弱化边框和控件，让内容像文章一样成为视觉中心。

C · 沉浸式无框阅读主题

正文体验更安静，适合长文档；但表格、配置备注和紧凑弹窗中的操作可发现性较弱。
