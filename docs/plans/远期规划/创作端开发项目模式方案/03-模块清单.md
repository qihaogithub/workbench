# 03 - 模块清单

## agent-service 层

| 模块 | 位置 | 职责 |
|------|------|------|
| Review Session 管理 | `packages/agent-service/src/review/session.ts` | session CRUD、多用户访问、dev server 生命周期管理、版本链管理 |
| 构建管理器 | `packages/agent-service/src/review/build.ts` | 后台异步 npm run build、dist_v{N}/ 目录管理、截图生成、dev server spawn/kill |
| 静态文件服务 | `packages/agent-service/src/review/static-serve.ts` | fastify-static serve dist_v{N}/，仅用于历史版本快照浏览 |
| HTTP 代理层 | `packages/agent-service/src/review/proxy.ts` | 基于 `@fastify/http-proxy`，始终代理 dev server，负责 HTML 注入、WS 透传 |
| Manifest 生成 | `packages/agent-service/src/review/manifest.ts` | 调用 Codex CLI 分析项目 → 校验 → 降级 |
| Codex CLI Executor | `packages/agent-service/src/review/executor.ts` | `codex exec --json` 子进程管理、JSONL 解析 |
| 任务队列 | `packages/agent-service/src/review/task-queue.ts` | 串行队列、状态管理、完成后自动触发 build 快照 |
| MCP Server | `packages/agent-service/src/review/mcp.ts` (可选) | `review_start`、`review_status` 工具，代理到内部 API |
| 类型定义 | `packages/agent-service/src/review/types.ts` | Session、Manifest、Annotation、Task、SnapshotVersion 等 |
| WebSocket 事件扩展 | `packages/agent-service/src/routes/ws-event-router.ts` (修改) | 新增 review 事件类型 |
| Pi Agent 配置 | `packages/agent-service/src/backends/pi-agent.ts` (修改) | 新增 `reviewer-codex` mode |
| 工具权限 | `packages/agent-service/src/backends/pi-tools/permissions.ts` (修改) | `REVIEWER_CODEX_PERMISSIONS` |
| API 路由 | `packages/agent-service/src/routes/` (新建) | `POST /api/review-sessions`、`GET /api/review-sessions/:id`、`GET /api/review-sessions/:id/snapshot/:version` 等 |

## author-site 前端层

| 模块 | 位置 | 职责 |
|------|------|------|
| 开发项目入口 | 项目列表页集成 (现有文件修改) | 列表混合展示、类型标签区分、新建开发项目对话框 |
| 开发项目页面 | `packages/author-site/src/app/review/[sessionId]/page.tsx` (新建) | 开发项目主页面 |
| 画布预览 | 复用现有画布组件 | 多 iframe 画布网格 |
| 单页预览 | 复用现有预览组件 | 单页全尺寸预览 |
| 标注 UI | `packages/author-site/src/app/review/[sessionId]/components/` (新建) | 标注气泡、高亮框 |
| 任务面板 | `packages/author-site/src/app/review/[sessionId]/components/TaskPanel.tsx` (新建) | 任务队列 UI，右侧面板「配置」Tab 替换为「任务」Tab |
| 可视化编辑 | 复用 `<VisualPropertyPanel>` | 编辑 Tab 复用，落点改为本地预览（不写数据），满意后 AI Chat 提交 |
| 页面导航 | 复用左侧 Tabs 框架，数据源切换 | 页面树形导航（按 manifest.states 构建），替换 project-core 数据源 |
| AI Chat | 复用 ai-chat-shared | 对话 + 标注上下文注入 |
| 标注脚本 | `packages/author-site/public/_review/annotation.js` (新建) | 注入到 iframe 的标注交互脚本 |

- `project-scaffold` — 不涉及
- `project-cli` — 不涉及
- `sketch-core` / `sketch-react` — 不涉及
- `screenshot-service` — 标注截图由前端直接截取，不依赖截图服务
