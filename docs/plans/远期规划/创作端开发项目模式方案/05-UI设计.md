# 05 - UI 设计

## 开发项目页面布局

与创作端编辑页共享 `ResizablePanelGroup` 三栏骨架（`[25, 50, 25]`），差异仅在 Tab 的显隐和内容：

```
┌──────────────────────────────────────────────────────────────────┐
│  创作端 - 活动名称 (开发项目)         [版本: v3 ▾] [已连接] 🔗  │
├──────────────┬──────────────────────────────────┬────────────────┤
│ 左侧  [AI│页面]│  预览区                 [画布│单页]│  右侧 [编辑│任务] │
│              │                                  │                │
│ 🤖 AI 对话   │  ┌──────┐ ┌──────┐ ┌──────┐   │ ✏️ 编辑        │
│ ┌──────────┐ │  │ 首页  │ │抽奖页│ │结果页│   │ ┌────────────┐ │
│ │用户: 按钮│ │  │[♦标注]│ │      │ │      │   │ │ 颜色: #FF0000│ │
│ │改成红色..│ │  └──────┘ └──────┘ └──────┘   │ │ 字号: 16px  │ │
│ │          │ │  ┌──────┐ ┌──────┐            │ │ 圆角: 8px   │ │

│              │                                  │ ── 切换到任务 Tab ─│
│ ── 切换到页面 Tab ──                            │                │
│              │                                  │ 📋 任务列表     │
│ 📄 首页      │                                  │ 🔄 执行中 #2    │
│  └ 默认     │                                  │ ⏳ 等待中 #3    │
```

### 与创作端编辑页的 Tab 差异

| 位置 | 创作端编辑页 | 开发项目页 | 说明 |
|------|-----------|-------------|------|
| 左侧栏 Tab | `[AI] [页面] [文件] [版本]` | `[AI] [页面]` | 去掉文件和版本 Tab；页面树数据源切换为 Manifest |
| 右侧栏 Tab | `[编辑] [配置]` | `[编辑] [任务]` | 编辑复用但落点为本地预览；配置替换为任务列表 |
| 预览区渲染 | 编译后沙箱 iframe | dev server 代理 iframe | `PreviewPanel` 新增 `renderMode` 参数 |
| 顶栏 | 项目名称 | 项目名称 + 版本选择器 + 连接状态 | 顶栏组件扩展 |
