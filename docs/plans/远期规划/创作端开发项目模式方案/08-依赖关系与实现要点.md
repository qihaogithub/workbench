## 关键集成点

### 1. agent-service mode 体系扩展

**现有模式**：`AgentConfig.toolMode` 类型为 `"workbench" | "viewer-readonly"`，定义在 [core/types.ts](file:///e:/重要文件/Programming/1_Work/opencode-workbench/packages/agent-service/src/core/types.ts#L41-L55)。

**需要扩展**：

```typescript
// core/types.ts - AgentConfig.toolMode 扩展
toolMode?: "workbench" | "viewer-readonly" | "reviewer-codex";
```

```typescript
// services/viewer-readonly-mode.ts（或重命名为 agent-modes.ts）
export type AgentMode = "workbench" | "viewer-readonly" | "reviewer-codex";

export function normalizeAgentMode(value: unknown): AgentMode {
  if (value === "viewer-readonly") return "viewer-readonly";
  if (value === "reviewer-codex") return "reviewer-codex";
  return "workbench";
}
```

**依赖**：`normalizeAgentMode()` 在以下文件中被调用：
- [agent.ts](file:///e:/重要文件/Programming/1_Work/opencode-workbench/packages/agent-service/src/routes/agent.ts#L131) (HTTP 消息路由)
- [websocket.ts](file:///e:/重要文件/Programming/1_Work/opencode-workbench/packages/agent-service/src/routes/websocket.ts#L196) (WS 连接和消息路由)

### 2. Pi Agent 工具集扩展

**现有工具创建**：`createWorkbenchTools()` 在 [pi-tools/index.ts](file:///e:/重要文件/Programming/1_Work/opencode-workbench/packages/agent-service/src/backends/pi-tools/index.ts#L70-L80)，根据 `options.mode` 返回不同工具集。

### 5. Review Session 与现有 Agent Session 的关系

| | Agent Session（现有） | Review Session（新增） |
|------|------|------|
| **生命周期** | 随 Agent 创建/销毁 | 独立于 Agent，仅靠空闲超时 |
| **工作空间** | `workspaceManager.create()` 临时/项目目录 | 直接持有 `projectPath` |
| **Pi Agent** | `agentManager.getOrCreate()` → Pi Agent 实例 | 对话时创建临时 Pi Agent（`reviewer-codex` 模式） |
| **存储** | `sessionStore`（内存） | 需新增持久化存储 |

**关键决策**：Review Session **不**复用 `sessionStore` 和 `agentManager`。它有自己的生命周期管理：
- dev server 由 agent-service 管理子进程
- 对话 Pi Agent 实例按需创建/销毁
- Session 数据（manifest、annotations、task queue）独立存储

### 6. dev server 子进程管理

**新增依赖**：`child_process.spawn()` — Node.js 内置，无需额外依赖。

```typescript
// packages/agent-service/src/review/dev-server.ts

import { spawn, ChildProcess } from "child_process";
import getPort from "get-port"; // 需要新增依赖

export async function spawnDevServer(projectPath: string): Promise<{
  process: ChildProcess;
  url: string;
}> {
  const port = await getPort(); // 自动找空闲端口
  // 检测框架类型，选择启动命令
  const proc = spawn("npm", ["run", "dev", "--", "--port", String(port)], {
    cwd: projectPath,
    stdio: "pipe",
  });
  // 等待 dev server 就绪（监听 stdout 特定输出）
  // 返回 url 和子进程引用
}
```

**依赖新增**：`get-port`（找空闲端口）、可能需要 `wait-on`（等待服务就绪）。

### 10. author-site 开发项目页面集成

**现有编辑器页面**：[demo/[id]/edit/page.tsx](file:///e:/重要文件/Programming/1_Work/opencode-workbench/packages/author-site/src/app/demo/[id]/edit/page.tsx) 是三面板布局的参考实现。

**复用组件**：

**开发项目页面与编辑器页面的关键区别**：

- 不需要草图编辑器、代码编辑器、文件树、版本历史等创作端特有组件

**可复用的现有基础设施**：

| 现有模块 | 文件 | 复用方式 |

| iframe 同域通信模式 | `PreviewPanel.tsx` | Review 标注通信直接复用 postMessage 模式 |
| 元素选择 + 高亮 | `iframe-template.ts` `__VISUAL_EDIT__` | 标注脚本参考现有 hover/select 逻辑 |
