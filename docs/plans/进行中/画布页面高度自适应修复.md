# 画布页面高度自适应修复

> 创建日期：2026-07-28  
> 状态：代码已落地，浏览器端验证未通过（问题依然存在）

## 问题

画布中 high-fidelity-react 页面存在两个 bug：
1. **底部露白**：卡片高度 > 真实内容高度，底部露出白色背景
2. **高度不随配置变化**：配置项改变页面实际高度后，卡片高度固定不变

## 根因

高度链路存在 5 处"只增不减"限制：

| # | 文件 | 限制行为 |
|---|------|----------|
| 1 | `iframe-template.ts:1620` | `#root { min-height: 100vh; }` 强制 body ≥ 设计高度 |
| 2 | `CanvasPageItem.tsx` `handleContentHeightChange` | 仅 `> designHeight` 时更新，变矮 return |
| 3 | `canvas-layout.ts` `resolveCanvasContentHeightLayout` | `if (contentHeight <= size.height) return null` |
| 4 | `canvas-layout.ts` `normalizeCanvasPageLayout` | `Math.max(layout.height, size.height)` 顶回设计高度 |
| 5 | `preview-scale.ts` `computePreviewScale` | 仅 `> designHeight` 走按宽缩放分支 |

## 已实施修改

1. `iframe-template.ts`：删除 `#root { min-height: 100vh; }`
2. `CanvasPageItem.tsx`：双向更新 + 50px 守卫 + `iframeEffectiveHeight` 双向判断
3. `canvas-layout.ts`：删除提前 return + 保留持久化高度
4. `preview-scale.ts`：`!== designHeight` + `Math.max(designHeight, effectiveHeight)`
5. `canvas-layout.test.ts`：更新断言 + 新增缩小场景用例

## 验证结果

- ✅ 单元测试：author-site 10/10 通过，author 952/952 通过，viewer 6/6 通过
- ✅ 类型检查：author-site、viewer-site 无错误；demo-ui 28 个错误为改动前已存在的环境问题
- ❌ **浏览器端：问题依然存在**

## 当前状态与排查方向

代码层面的 5 处限制已解除，但浏览器端仍表现原始问题。可能原因：

1. **iframe 内容高度反馈回路**：页面内 `100vh` / `min-h-screen` 仍把 body 撑到设计高度，ResizeObserver 上报的仍是设计高度
2. **postMessage RESIZE 链路**：iframe 上报的高度是否真的传到 `handleContentHeightChange`？
3. **布局持久化覆盖**：旧的持久化布局数据（`Math.max` 写入的）可能仍被加载并覆盖新逻辑，需清理 localStorage
4. **preview-scale 裁剪**：wrapper 的 `overflow: hidden` 是否被子级样式覆盖？
5. **prototype-html-css 页面**：本方案仅针对 high-fidelity-react，prototype-html-css 走 Shadow DOM 无测量通道

## 相关代码

**核心链路**：`iframe-template.ts` → `CanvasPageItem.tsx` → `canvas-layout.ts` → `preview-scale.ts`  
**测试**：`canvas-layout.test.ts`  
**布局持久化**：`author-site/src/app/api/sessions/[sessionId]/canvas-layout/route.ts`

## 下一步

- DevTools 观察 iframe 内 `document.body.getBoundingClientRect().height`，确认 ResizeObserver 上报值
- `handleContentHeightChange` 入口加 `console.log`，验证消息链路
- 清理浏览器 localStorage 中的 canvas layout 缓存
- 若上述正常，排查页面内 `100vh` 样式，考虑在 iframe 模板注入 `html, body { height: auto; }`
