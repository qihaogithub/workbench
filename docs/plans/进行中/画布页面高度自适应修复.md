# 画布页面高度自适应修复

> 创建日期：2026-07-28
> 状态：测量链路已修复，单元/类型验证通过；待浏览器端确认画布完整展示

## 问题

画布中页面卡片被截断为配置的预览高度，超出部分被裁剪。单页面模式可滚动查看，但画布模式页面无法滚动，用户无法查看完整页面。

## 根因

iframe 内的高度测量只上报 `document.body` 的 `contentRect.height`。当页面使用 `h-screen` / `height: 100vh`（生成页面常见）时，body 高度被钉死在 iframe 视口高度（= 设计/预览高度），超出视口的内容虽溢出但从未被上报，导致画布卡片不会长高，内容被外层 `overflow: hidden` 裁剪。

此前已解除高度链路上 5 处“只增不减”限制，但测量源头不上报完整高度，问题依然存在。

## 已实施修改

1. `demo-ui/src/iframe-template.ts` 与 `shared/src/demo/iframe-template.ts`：新增 `measureFullContentHeight()`，取三者最大值——body 自身高度、body 直接子元素最大下边缘、文档可滚动高度（仅在内容溢出视口时采用，以保留“内容变矮时卡片收缩”行为）；ResizeObserver 回调与 WAKE 处理改用该函数上报完整内容高度。
2. （此前）解除高度链路 5 处限制：`#root min-height`、`CanvasPageItem.tsx` 双向更新、`canvas-layout.ts` 提前 return 与 `Math.max` 顶回、`preview-scale.ts` 分支判断。
