| P1-8 | agent-service | Task Queue：串行队列、状态管理、完成后自动触发 build 快照 | 高 |
| P1-9 | agent-service | WebSocket 事件扩展：task_queued / task_status / codex_event / task_result | 高 |
| P1-10 | agent-service | Pi Agent 翻译官模式：System Prompt + REVIEWER_CODEX_PERMISSIONS | 高 |
| P1-11 | author-site | 项目列表开发项目集成：列表混合展示、类型标签、「新建开发项目」按钮和对话框 | 高 |
| P1-12 | author-site | 新建 `/review/[sessionId]/` 路由和主页面：画布截图网格 + 单页 iframe 标注 + 版本选择器 + 连接状态指示器 | 高 |
| P1-13 | author-site | 标注注入脚本 `public/_review/annotation.js`：元素点击高亮、标注气泡 | 高 |
| P1-14 | agent-service | 需求分类逻辑：`reviewer-codex` mode 中实现 UI/Logic 需求判断和分流 | 高 |
