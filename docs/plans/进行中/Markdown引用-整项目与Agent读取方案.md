# Markdown 引用：整项目与 Agent 读取

## 背景与目标

用户已确认整项目引用双入口，以及 Agent 按权限读取引用内容并用于图片制作。保留现有跨项目、页面、配置定义、文档引用语义。

## 范围与方案

- 第一阶段：项目名称切换范围、行尾按钮直接插入；菜单内另保留整项目入口。复用 wb URI、展示浮层和目标端重验。
- 第二阶段：只读引用解析入口，绑定服务端操作者，按既有项目权限校验。项目返回目录，其他类型返回有界内容和后续引用。图片按来源重新校验后提供像素给视觉/制图工具。
- 不改变发布端权限、不开启 live Workspace 子 Agent 写权限、不改用户项目数据。不递归加载整个项目，不把引用资料视为指令。

## 验证方式

## 风险与待验证

- 待用户在实际项目验收新标签打开和真实供应商制图；本轮未调用收费制图服务，也未部署或提交。
- live Workspace 仍禁止 delegateTask；主 Agent 使用受控参考图工具，不开放额外写入。外部图片 URL 不做任意服务端抓取，未支持来源明确报告。
- 供应商不支持参考图输入时直接拒绝，不静默降级为纯文本生图。未读正文不能表述为已读取。
- demo-ui 全量测试仍有 2 个既有 `PageConfigPanel` 用例失败；本次引用相关测试与类型检查通过，失败项不在本次改动范围内。
