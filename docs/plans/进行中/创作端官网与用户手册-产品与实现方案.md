# 创作端 OneFlow 官网与用户手册方案

> 状态：实施中（核心页面、路由和内容已落地）
> 更新时间：2026-09-03

## 1. 背景与目标

创作端需要一个面向访客的官方入口，同时保留登录用户进入既有项目工作台的效率。根路径改为 OneFlow 官网：匿名用户看到产品介绍，已登录用户由 Proxy 直接进入 `/workbench`。官网之外提供独立、公开、可版本化的用户手册，帮助用户从第一次登录走到发布、分享和排障。

本方案只覆盖创作端公开官网、用户手册、工作台入口与相关鉴权跳转，不改变现有 JWT Cookie、Bearer 认证、用户表、项目权限、浏览端和嵌入协议。

## 2. 路由契约

| 路径 | 访问规则 | 页面职责 |
| --- | --- | --- |
| `/` | 公开；登录用户重定向 | 官网首页 |
| `/manual` | 公开 | 手册目录、分类和搜索 |
| `/manual/[slug]` | 公开 | 手册文章、目录、前后导航 |
| `/workbench` | 必须登录 | 当前项目工作台（原根路径能力） |
| `/login`、`/register` | 仅未登录 | 认证页面，成功后进入安全目标或工作台 |
| `/demo/[id]/edit`、`/cli` | 必须登录 | 既有创作能力 |
| `/viewer/*`、`/embed/*` | 沿用既有公开规则 | 使用端和嵌入页面 |

Proxy 使用精确的路由前缀匹配。匿名访问受保护页面时将 pathname 和 query string 写入登录页 `redirect`；已登录访问 `/`、`/login` 或 `/register` 时进入 `/workbench`。`getSafeRedirectPath` 仅接受单斜杠站内路径，拒绝 `//`、反斜杠、控制字符、完整 URL 和 `javascript:` 等值。工作台服务端仍调用 `getCurrentProjectActor()`，作为 Proxy 之外的第二道校验。

## 4. 用户手册设计

手册内容位于 `packages/author-site/src/content/manual/`，通过受控 Markdown 文件和 TypeScript manifest 维护，不直接渲染 `docs/项目文档/` 或用户上传内容，不提供在线 CMS。初始文章：

- 开始使用：`quick-start`、`workspace-basics`
- 项目创作：`projects-and-pages`、`ai-creation`
- 配置与预览：`config-and-preview`
- 协同与版本：`collaboration-and-versioning`
- 模板与知识库：`templates-and-knowledge`
- 发布与集成：`publish-share-embed`、`figma-and-cli`
- 管理员：`admin-and-models`
- 排障：`troubleshooting`、`faq`

内容模型 `ManualArticleMeta` 包含 `slug`、`title`、`description`、`section`、`order`、`updatedAt`、`tags` 和 `content`。manifest 测试保证 slug 唯一、字段完整、文章顺序稳定、内部 `/manual/*` 链接指向已知 slug。

Markdown 渲染器关闭原始 HTML、自动链接和事件属性，仅允许站内路径、`https`、必要的 `mailto` 以及 `/manual/` 下的本地图片；标题生成稳定锚点；代码块只展示文本。文章页服务端生成 metadata 和静态参数，桌面端展示目录，移动端使用折叠目录，提供更新时间、版本、上一篇/下一篇和返回工作台 CTA。

## 8. 验证方式

```bash
pnpm --filter @workbench/author-site typecheck
pnpm --filter @workbench/author-site test
pnpm check:author
pnpm test:e2e
pnpm build
```

关键浏览器验收：匿名 `/` → 官网；官网进入手册和文章；匿名进入工作台 → 登录并保留 query；登录后 `/` → `/workbench`；匿名编辑深链登录后回原页；已登录仍可阅读手册；375×812 移动视口下菜单、目录和 CTA 可用。

## 9. 风险与后续

- 旧根路径书签指向项目列表：项目尚未上线，发布说明明确 `/workbench` 为工作台入口。
- 无效 JWT：Proxy 仅做快速路由判断，工作台服务端再次验证用户。
- 开放重定向：统一安全函数和单元测试覆盖外部 URL、协议相对 URL、反斜杠和控制字符。
- 公开页误调用项目 API：官网和手册组件只接收静态内容；后续 E2E 可增加网络请求断言。
- 手册与能力脱节：功能变更时同步更新对应文章的更新时间和版本，项目文档模块见 [14-官网与用户手册](../../项目文档/创作端/14-官网与用户手册/)。
