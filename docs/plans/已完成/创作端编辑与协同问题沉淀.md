# 创作端编辑与协同问题沉淀

记录 Markdown 编辑器（DocumentEditor/Milkdown）、协同、自动保存、复原、评论 pin 相关问题的现象、根因、修复与验证结论。按条目维护，只保留当前仍有价值的信息。

## 1. 原型页（prototype-html-css）评论 pin 不跟随滚动，悬浮在页面上

- **现象**：原型页预览中，评论 pin 固定在页面某处，上下滚动时不会随目标元素移动，导致用户无法判断评论对应哪个元素。
- **根因**（`packages/demo-ui/src/comment/CommentLayer.tsx`）：
  - **坐标模型错误**：原型页 `.prototype-root` 是固定高度 + `overflow:auto` 的滚动容器，内容在容器内部滚动、容器盒的 `getBoundingClientRect` 不随滚动变化。旧代码用 `rootRect.top + yRatio * rootRect.height` 定位（相对可见盒），滚动时不变 → pin 悬浮。应与 iframe 路径一致：按内容 `scrollWidth/scrollHeight` 定位，再减去 `scrollLeft/scrollTop`。
  - **存储语义错误**：创建评论时 `yRatio` 用可见盒比例而非内容比例，即使换个渲染公式也无法缺少创建时滚动信息来重建内容位置。
  - **滚动监听挂错对象**：`scroll` 事件**不穿越 shadow 边界**（实测定：`.prototype-root` 内滚动只触发 shadow 内监听，宿主 `[data-prototype-preview]` 与 document 的 capture 监听都收不到）。旧代码把监听挂宿主上，原型页滚动永远不触发重算。
- **修复**：新增 `packages/demo-ui/src/comment/pin-layout.ts` 纯函数 `computePrototypePinRatio`（点击→内容归一化坐标）与 `computePrototypePinPosition`（内容坐标→容器像素，跟随滚动），创建与渲染共用；滚动监听改为轮询等待 shadowRoot 出现后挂到 `.prototype-root`（MutationObserver 跟踪重建，避免宿主子树观察器看不到 shadow 内容）。
- **验证**：浏览器实测滚动 0→300→600→900 时 pin 逐级跟随（delta≈scrollTop×scale）；`pin-layout.test.ts` 7 用例覆盖非滚动/滚动往返一致性、滚动跟随、横向滚动、越界钳制。demo-ui typecheck + 55 测试通过，author-site typecheck 通过。
- **注意**：此修复改变 pin 存储语义（可见盒比例→内容比例）。修复前在**可滚动**原型页上创建的旧评论，其存储比例无法重建内容位置，滚动后不复位（预上线无需迁移，重新创建即可）；非滚动页两者一致、无回归。
- **防回退**：改 pin 定位时，`.prototype-root` 是内容滚动容器，必须用 scroll* 坐标并监听 shadow 内元素；不要用 `rootRect + 比例` 或监听宿主。
- **相关文件**：`packages/demo-ui/src/comment/CommentLayer.tsx`、`packages/demo-ui/src/comment/pin-layout.ts`、`packages/demo-ui/src/comment/pin-layout.test.ts`

## 1. Milkdown 浮动 UI（斜杠菜单/工具提示/链接提示）堆叠泄漏

- **现象**：Markdown 编辑器在编辑页/弹窗中，斜杠菜单、选中文本格式条、链接工具提示同时可见并纵向堆叠在编辑区左上，且不受控制地常驻显示。
- **根因**：Milkdown 的 `SlashProvider` / `TooltipProvider` / `link-tooltip` 把浮动元素 append 到编辑器根节点 `.milkdown` 下、`.mk-editor` 的**兄弟位置**（不是内部），元素默认 `position: static`，仅靠 `data-show="true"/"false"` 控制显隐。此前 CSS 里没有能命中它们的作用域规则（误写成 `.mk-editor [data-show="false"]`，永远匹配不到），导致三个悬浮层以 `display: block` 泄漏进文档流并纵向堆叠。
- **修复**：`DocumentEditor` 的 `editorBaseStyles` 用 `.milkdown` 作用域隐藏未显示的浮动项，并把显示项提升为 `position: fixed; z-index: 9999`（provider 用 `computePosition` 计算的是视口坐标，必须 `position: fixed` 才生效）。`markdown/native-ui.tsx` 的 `SlashView`/`TooltipView` 根节点加了 `md-floating` 标记类，链接提示用现成的 `milkdown-link-preview` / `milkdown-link-edit` 类。
- **验证**：隔离页实测全部 `[data-show=false]` 项 `display:none`；`data-show=true` 时 `position:fixed`、z-index 生效、provider 计算的 left/top 正确。demo-ui 48 测试通过。
- **防回退**：改浮动 UI 样式时，作用域必须用 `.milkdown`（挂载点），不要用 `.mk-editor`（浮动元素是它的兄弟）。
- **相关文件**：`packages/demo-ui/src/DocumentEditor.tsx`、`packages/demo-ui/src/markdown/native-ui.tsx`、`docs/项目文档/创作端/04-配置与预览/技术/05_共享组件架构设计.md`
