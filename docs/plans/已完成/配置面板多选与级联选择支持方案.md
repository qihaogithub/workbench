# 配置面板多选与级联选择支持方案

> **创建日期**: 2026-08-02
> **状态**: 待实施
> **目标**: 配置表单支持枚举多选（checkbox 组）和级联选择（省市区联动等层级数据选择）

---

## 1. 现状

| 能力 | 现状 | 组件 |
|------|------|------|
| 单选下拉 | ✅ 完整支持 | shadcn/ui `Select` |
| 多选 | ❌ 不支持 | — |
| 级联选择 | ❌ 不支持 | — |

当前 `type: "enum"` 在 `config.ts` 中被编译为 `{ type: "string", enum: [...] }`，运行时通过 `FieldRenderer.tsx:291-325` 渲染为 shadcn/ui `Select` 单选下拉。

## 2. 方案设计

### 2.1 多选（type: "enum" + multiple: true）

#### config.ts 语法

```typescript
tags: {
  type: "enum",
  title: "标签",
  enum: ["tech", "design", "product", "marketing"],
  enumNames: ["技术", "设计", "产品", "营销"],
  multiple: true,
  default: ["tech", "design"],
}
```

#### 编译器输出（config.schema.json）

```json
"tags": {
  "type": "array",
  "title": "标签",
  "ui:widget": "multiselect",
  "default": ["tech", "design"],
  "items": {
    "type": "string",
    "enum": ["tech", "design", "product", "marketing"],
    "enumNames": ["技术", "设计", "产品", "营销"]
  },
  "ui:options": {
    "group": "标签"
  }
}
```

**设计理由**：
- `type: "array"` 语义正确，多选天然是数组
- `ui:widget: "multiselect"` 告知 FieldRenderer 使用多选组件而非 ImageListWidget
- `items.enum` 承载可选项列表，符合 JSON Schema 规范
- 页面代码接收 `string[]`，直接使用

#### 反向编译器

`decompileSchema` 检测到 `type: "array"` + `ui:widget: "multiselect"` 时，反编译为 `type: "enum", multiple: true`。

---

### 2.2 级联选择（新增 type: "cascade"）

#### config.ts 语法

```typescript
region: {
  type: "cascade",
  title: "地区",
  default: ["zhejiang", "hangzhou"],
  options: [
    {
      value: "zhejiang",
      label: "浙江",
      children: [
        { value: "hangzhou", label: "杭州" },
        { value: "ningbo", label: "宁波" },
      ],
    },
    {
      value: "jiangsu",
      label: "江苏",
      children: [
        { value: "nanjing", label: "南京" },
        { value: "suzhou", label: "苏州" },
      ],
    },
  ],
}
```

#### 编译器输出（config.schema.json）

```json
"region": {
  "type": "array",
  "title": "地区",
  "ui:widget": "cascade",
  "default": ["zhejiang", "hangzhou"],
  "ui:options": {
    "cascadeOptions": [
      {
        "value": "zhejiang",
        "label": "浙江",
        "children": [
          { "value": "hangzhou", "label": "杭州" },
          { "value": "ningbo", "label": "宁波" }
        ]
      },
      {
        "value": "jiangsu",
        "label": "江苏",
        "children": [
          { "value": "nanjing", "label": "南京" },
          { "value": "suzhou", "label": "苏州" }
        ]
      }
    ]
  }
}
```

**设计理由**：
- `type: "cascade"` 作为新增的 config.ts 类型，与 `enum`/`color`/`image` 同级
- `options` 承载嵌套层级数据，编译后存入 `ui:options.cascadeOptions`
- 运行时 `type: "array"`，页面代码接收 `string[]`（从根到叶的路径值数组）
- 选项数据不注入页面 props，仅用于配置面板渲染

#### 反向编译器

`decompileSchema` 检测到 `ui:widget: "cascade"` 时，提取 `ui:options.cascadeOptions`，反编译为 `type: "cascade", options: [...]`。

## 3. UI 组件设计

### 3.1 MultiSelect 组件（新增）

位置：`packages/demo-ui/src/MultiSelect.tsx`

基于 shadcn/ui 的 `Popover` + `Command` + `Checkbox` 构建：

- 触发按钮显示已选标签数量（如 "技术, 设计 +1"）
- 展开面板内每个选项带 Checkbox，支持搜索过滤
- 全选/取消全选快捷操作
- 已选项按钮顶部展示，点击 × 取消
- 交互约束：展开时不触发父级滚动（`modal` 模式）

**Props**:
```typescript
interface MultiSelectProps {
  options: Array<{ value: string; label: string }>;
  value: string[];
  onChange: (value: string[]) => void;
  placeholder?: string;
}
```

### 3.2 CascadeSelect 组件（新增）

位置：`packages/demo-ui/src/CascadeSelect.tsx`

基于 shadcn/ui 的 `Popover` + 手写两列布局构建：

- 触发按钮显示已选完整路径（如 "浙江 / 杭州"）
- 展开面板分两列：左列一级选项，右列二级选项
- 点击一级自动展开二级
- 选中叶子节点自动关闭
- 支持搜索当前可见层级

**Props**:
```typescript
interface CascadeOption {
  value: string;
  label: string;
  children?: CascadeOption[];
}

interface CascadeSelectProps {
  options: CascadeOption[];
  value: string[];
  onChange: (value: string[]) => void;
  placeholder?: string;
}
```

> 第一期只支持 2 级。3 级以上可通过递归组件扩展，但当前需求场景以省市区、分类子类为主，2 级够用。

## 5. 任务清单

### 阶段一：编译器

- [ ] `VALID_TYPES` 新增 `"cascade"`
- [ ] `compileFieldDescriptor` 新增 `case "cascade"`：编译 `options` → `ui:options.cascadeOptions`，输出 `{ type: "array", ui:widget: "cascade" }`
- [ ] `compileFieldDescriptor` 修改 `case "enum"`：当 `multiple: true` 时，输出 `{ type: "array", ui:widget: "multiselect", items: { type: "string", enum/enumNames } }`；同时在 switch 后的通用循环中拦截 `enum`/`enumNames`/`default` 不写入顶层
- [ ] `decompileSchema` → `reverseType`：**在 imageList 判断之前**检测 `ui:widget === "multiselect"` → 返回 `"enum"`；检测 `ui:widget === "cascade"` → 返回 `"cascade"`

## 6. 风险与约束

| 风险 | 缓解 |
|------|------|
| 级联选择选项数据可能很大（如全国省市区 3000+ 条），config.ts 体积膨胀 | 第一期只做 2 级，后续可通过 `optionsUrl` 远程加载扩展 |
| `reverseType` 中 multiselect 与 imageList 的 schema 形状相同（均为 `type: "array"` + `items: { type: "string" }`），仅靠 `ui:widget` 区分 | `reverseType` 的 array 分支必须先检查 `ui:widget`（multiselect/cascade），再回退到 imageList 检测，确保带 widget 标记的字段不走 imageList 分支 |
| 页面代码类型推断：多选值为 `string[]`，级联值为 `string[]`，与单选 `string` 不一致 | 在 Prompt 中说明类型差异；TypeScript 侧通过 `DemoProps` 标注 |
| `VALID_TYPES` 扩展 `"cascade"` 后需注意编译/反编译路径一致性 | `compileFieldDescriptor` 通过 `VALID_TYPES.has()` 校验类型名，必须加入 `"cascade"`；`reverseType` 不依赖 `VALID_TYPES`，通过显式 `ui:widget` 检测区分 imageList/multiselect/cascade |
