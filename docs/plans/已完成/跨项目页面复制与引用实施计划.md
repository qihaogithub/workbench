## 实施步骤

### Step 1: 数据模型变更

**涉及文件：**

- `packages/shared/src/workspace.ts` — `DemoPageMeta` 增加 `reference?` 字段
- `packages/demo-ui/src/types.ts` — `CanvasPageData` 增加 `schema`、`isReference`、`sourceProjectId` 字段

**内容：**
- DemoPageMeta 增加 `reference?: { sourceProjectId: string; sourcePageId: string }`
- CanvasPageData 增加 `schema?: string`、`isReference?: boolean`、`sourceProjectId?: string`

**验证：** `pnpm typecheck`

---

### Step 2: 复制修复 — schema 携带 + 粘贴写入分离

**涉及文件：**

- `packages/demo-ui/src/PreviewCanvas.tsx` — 复制逻辑中从页面的完整数据中读取 schema 写入 CanvasPageData.schema
- `packages/author-site/src/app/demo/[id]/edit/page.tsx` — `handlePastePages` 修正写入逻辑
- `packages/author-site/src/lib/fs-utils.ts` — 检查 `createWorkspaceDemoPage` 和 `copyWorkspaceDemoPage` 是否需扩展

**内容：**
- PreviewCanvas 复制时：从源页面完整数据中获取 `config.schema.json` 原始字符串，放入 `CanvasPageData.schema`
- handlePastePages 粘贴时：将 `schema` 写入目标页面的 `config.schema.json`，`configData` 写入项目级或页面级配置值（与 schema 分离）
- 修复 sketchScene 数据携带（当前按 code 写入，确认是否需保留此行为）

**验证：** `pnpm check:author`

---

### Step 3: 引用创建 API

**涉及文件：**

- `packages/author-site/src/app/api/projects/[projectId]/reference-pages/route.ts` — 新增 API 路由
- `packages/author-site/src/lib/project-api.ts` — 新增 createReferencePages 方法
- `packages/shared/src/contracts.ts` — 检查是否需要扩展 API 类型

**内容：**
- `POST /api/projects/{projectId}/reference-pages`
  - 请求体：`{ sourceProjectId, sourcePageIds: string[], sessionId }`
  - 校验：每个 sourcePageId 对应的页面是真实页面（非引用页）
  - 为每个源页面生成新 pageId
  - 写入目标项目的 workspace-tree.json，每条 DemoPageMeta 带 `reference` 字段
  - 不创建物理目录
  - 返回 `DemoPageMeta[]`
- 前端 API client 添加 `createReferencePages` 方法

**验证：** `pnpm check:author`

---

### Step 4: 引用页渲染 API

**涉及文件：**

- `packages/author-site/src/app/api/projects/[projectId]/reference-page/[pageId]/route.ts` — 新增 API 路由
- `packages/author-site/src/lib/project-api.ts` — 新增 getReferencePageContent 方法

**内容：**
- `GET /api/projects/{projectId}/reference-page/{pageId}?sessionId=xxx`
  - 从 workspace-tree 读取引用页的 reference 元数据
  - 从源项目读取页面文件（code, schema, config values, prototype, sketch 等）
  - 返回 `{ code, schema, configData, runtimeType }`
  - 源项目/页面不存在时返回 404
  - 鉴权：依赖现有 session 鉴权，源项目无权限时返回 403
- 前端 API client 添加 `getReferencePageContent` 方法

**验证：** `pnpm check:author`

---

### Step 5: 引用页画布渲染

**涉及文件：**

- `packages/demo-ui/src/CanvasPageItem.tsx` — 引用态渲染（加载中、正常、断开、无权限）
- `packages/demo-ui/src/PreviewCanvas.tsx` — 引用页初始化时加载远端内容
- `packages/author-site/src/app/demo/[id]/edit/page.tsx` — 引用页数据加载集成

**内容：**
- CanvasPageItem 识别 `isReference` 渲染分支：
  - 加载中：显示 loading spinner
  - 正常：渲染为 iframe/screenshot/prototype（与普通页面相同管线）
  - 断开引用：灰色占位框 + 断开链接图标 + "源页面不可用"
  - 无权限：显示"无权限访问源项目"
- 引用页增加锁定图标角标 + 透明度降低的视觉标识
- 双击引用页 → 不打开编辑面板，显示提示"此页面为引用，请在源项目中编辑"
- 引用页右键菜单：布局操作保留，编辑/配置隐藏；新增"查看源项目"、"转为副本"、"移除引用"
- 内容缓存：内存 Map key=`${sourceProjectId}:${sourcePageId}`，会话级别

**验证：** `pnpm check:demo-ui` + `pnpm check:author`

---

### Step 6: 粘贴选择器 UI

**涉及文件：**

- `packages/demo-ui/src/PreviewCanvas.tsx` — 粘贴事件增加跨项目检测 + 选择器弹窗
- `packages/demo-ui/src/components/PasteOptionsModal.tsx` — 新增选择器组件

**内容：**
- 粘贴事件检测：比对 `clipboardData.sourceProjectId` 与当前项目 ID
- 同项目：直接走复制流程（现有行为）
- 跨项目：弹出 PasteOptionsModal
- PasteOptionsModal：两个按钮 [复制] [引用]，选择后执行对应流程
- 引用流程：调用 `POST /api/reference-pages` → 将返回的引用页 meta 追加到画布

**验证：** `pnpm check:demo-ui` + `pnpm check:author`

---

### Step 7: 引用页右键菜单

**涉及文件：**

- `packages/demo-ui/src/PreviewCanvas.tsx` — 右键菜单条件渲染
- `packages/author-site/src/app/demo/[id]/edit/page.tsx` — "查看源项目"跳转逻辑、"转为副本"逻辑

**内容：**
- "查看源项目"：跳转到 `/demo/${sourceProjectId}/edit`（或对应路由）
- "转为副本"：调用现有复制 API 将引用页内容拉取到目标项目，创建物理文件，移除 reference 标记
- "移除引用"：从 workspace-tree 删除引用页条目，画布移除
- 右键菜单条件：引用页只显示布局操作 + 引用相关操作，不显示编辑/配置

**验证：** `pnpm check:author`

---

### Step 8: 错误处理与边界情况

**涉及文件：**

- 以上所有新增/修改文件

**内容：**
- 引用创建 API 校验：sourcePageId 必须是真实页面（非引用页）
- 删除引用页：不清理物理文件（物理文件不存在）
- 删除源页面/项目：引用页在渲染时返回 404 → 画布显示断开占位
- 引用页加载失败重试逻辑
- 项目级配置依赖：复制时只复制页面级内容，引用页通过源项目 API 自动包含项目级配置

**验证：** `pnpm check:author` + `pnpm check:demo-ui`

## 风险

- 引用页渲染依赖源项目 API 可用性，网络抖动可能影响目标项目加载体验
- 跨项目鉴权：当前依赖 session 鉴权，私有项目引用需要确认 API 鉴权是否覆盖跨项目场景
- 引用页内容缓存策略：会话级别缓存可能导致源更新后用户需要手动刷新才能看到最新内容
