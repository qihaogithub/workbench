# 创作端配置与预览问题沉淀

## 共享配置动态绑定未显示

- **现象**：高保真 React 页面通过 `props` 别名、点访问或模板字符串动态键消费项目级共享配置时，配置面板可能不展示“共享配置”。
- **影响范围**：依赖源码绑定识别来裁剪项目级 Schema 的 `high-fidelity-react` 与 `sketch-scene` 页面。
- **根因**：当前绑定提取器只识别 `const { field } = props` 解构，无法识别 `const p = props` 后的 `p.field` 与 ``p[`prefix${expression}suffix`]``。
- **最终结论**：提取器现接收项目级 Schema 字段作为候选集合；识别 props 别名、静态属性访问和模板键的稳定前后缀，再将动态模板匹配到真实 Schema 字段。无法证明绑定的字段继续隐藏，避免把所有共享配置错误展示给无关页面。
- **验证状态**：单测已覆盖 `p.activeSubject`、动态 `headerBg*`、动态 `progressBg*`、无关字段族排除与无稳定边界的动态键；`check:demo-ui`、author-site 配置面板目标测试及 author-site 类型检查通过。
- **项目事实**：长期规则已同步到 [`配置系统_需求文档.md`](../../项目文档/创作端/04-配置与预览/配置系统_需求文档.md) 与 [`03_表单生成器.md`](../../项目文档/创作端/04-配置与预览/技术/03_表单生成器.md)。
