# 工程质量 - 性能与低维护安全优化归档

> 完成日期：2026-08-20

## 最终结论

- Viewer 页面 Schema 改为并发加载，单页失败回退项目级默认配置；项目切换通过加载 generation 丢弃旧响应，并立即清空旧项目视图状态。
- 创作端截图请求按项目与页面共同隔离版本，项目切换清理批次、轮询和截图状态；编辑页卸载时清理配置持久化与截图再生定时器。
- 共享预览只在编辑模式注入布局写回回调，浏览端只读画布不再触发未定义回调。
- Agent Workspace Shell 只允许白名单中的单条命令，拒绝命令组合、重定向、命令替换、换行及 Node eval/print 参数；Snapshot Git 操作改用 argv，以 NUL 分隔格式解析特殊文件名，并拒绝回滚路径越出工作区。
- CI 与项目统一使用 Node 24；Docker builder 统一使用 frozen lockfile，并复制根补丁目录及实际依赖的 workspace 清单。
