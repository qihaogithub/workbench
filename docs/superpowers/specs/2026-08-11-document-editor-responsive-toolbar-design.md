# DocumentEditor 自适应顶部工具栏设计

> 日期：2026-08-11
> 状态：待实现

## 目标

让共享 `DocumentEditor` 的 Crepe 顶部工具栏在任意宿主宽度下保持单行。显示不下的原生工具项收纳到末尾“更多”按钮，用户可在浮层菜单中继续使用这些工具。

## 方案

- 新增独立的 TopBar 溢出控制器，由 `DocumentEditor` 在 Crepe 创建完成后挂载，并在销毁时清理。
- 控制器使用 `ResizeObserver` 监听工具栏可用宽度；按照原始 DOM 顺序保留前缀工具项，后续项移入“更多”菜单。标题下拉也作为一个完整工具项参与测量，避免被压缩或截断。
- “更多”只在存在溢出项时显示，使用语义化 `button`、`aria-expanded` 和菜单角色；点击工具项复用其原始交互，再关闭菜单并将焦点交还编辑器。
- 容器变宽时重新计算并恢复可容纳的原生工具项；窄到无法容纳普通项时，至少保留“更多”入口。
- 不修改 Crepe 的格式化命令、Markdown 模型、只读逻辑或消费方 API；只读时原生 TopBar 仍不显示。

## 失败与边界

- 不依赖固定断点或工具项名称，避免新增 Crepe 工具后遗漏适配。
- 多次 DOM 更新、菜单打开状态和编辑器卸载不会遗留观察器、菜单或文档级事件。
- 测量不可用的测试环境不应抛错；控制器退化为保留原有工具栏。

## 验证

- 为溢出控制器补充 jsdom 单测：窄宽度收纳、宽度恢复、菜单点击、无溢出不显示“更多”、键盘/ARIA 及销毁清理。
- 运行 `pnpm check:demo-ui`。
- 更新共享组件架构文档，说明 TopBar 的容器级自适应规则。
