# 按需创建项目与页面公约设计

## 目标

新建或打开创作端项目时，不自动产生项目公约或页面公约文件。用户通过文档视图的「新建/添加公约」入口，才会创建所选范围的公约。

## 方案

- 工作区初始化只保留目录、知识库、AI 记忆、页面清单与应用图，不再写入 `convention.md`。
- 工作区文件读取接口不再把读取项目公约视为创建动作；缺失文件按普通不存在处理。
- 文档视图基于实际存在的公约文件渲染目录：没有公约时只显示可新建入口；页面公约只显示已创建的页面。
- 用户选择新增项目或页面公约后，客户端以默认 Markdown 模板调用既有可编辑文件写入接口，写入成功后打开该文档。已有文件不会被覆盖。

## 边界与验证

现有公约保留且继续可读写；AI 读取缺失公约仍得到空内容。验证覆盖：初始化不创建、读取不创建、手动新建创建正确范围且侧栏只展示已存在条目。
