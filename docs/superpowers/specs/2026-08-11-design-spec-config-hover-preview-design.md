# 设计规格：配置项所在页面悬浮预览

## 目标

在创作端设计规格工作台的配置项素材池中，用户悬停任意配置项时都能看到该配置项所在页面的示意图。图片配置项还应在同一预览中显示当前默认图片。

## 交互与展示

- 悬停配置项整行（而非仅缩略图）或以键盘聚焦该项时，显示固定定位的非交互悬浮预览卡。
- 非图片配置项：卡片仅显示所在页面示意图。
- 图片配置项：卡片并列显示默认图片和所在页面示意图；默认图片采用现有安全来源和占位图规则。
- 卡片不展示底部配置项名称或页面名称文本；图片的 `alt` 文本保留，页面示意图仍有无障碍说明。
- 鼠标离开、焦点离开或组件卸载时关闭卡片；移动指针时卡片跟随并保持与指针的安全偏移。

## 数据与降级

- 继续使用配置项已有的 `scope`、`pageName` 和 `value`，不新增持久化字段或接口。
- 页面名称不可用时，沿用当前“页面”兜底生成示意图。
- 图片值缺失或不可用时，显示现有 SVG 占位图；不影响页面示意图展示。

## 实现边界

- 改动限制在 `DesignSpecConfigPanel` 与 `DesignSpecVisuals` 的悬浮预览状态及渲染；不改变拖拽绑定、筛选、点击放大或全屏查看行为。
- 抽取/调整预览渲染，使素材池与表格缩略图复用同一规则，避免图片与非图片出现不一致的卡片内容。

## 验收与测试

- 为所有配置类型添加/更新组件测试：悬停和键盘聚焦显示页面示意图；图片同时显示默认图；名称文本不再出现。
- 验证图片缺省值时的降级展示，以及离开后预览关闭。
- 运行 `pnpm --filter @workbench/author-site test` 中相关测试和 `pnpm --filter @workbench/author-site typecheck`。
