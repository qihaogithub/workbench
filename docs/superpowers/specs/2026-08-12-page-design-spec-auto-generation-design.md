# 页面设计规范自动创建与同步设计

## 背景与目标

创作端已有多文档的设计规范能力，但页面新增图片或动效配置项后，需要人工创建并绑定规范条目。该功能让页面级图片、动效配置自动具备对应的设计规范文档和条目，并在配置变化后保持同步。

## 范围

仅处理页面级配置项：

- 当页面存在图片或动效配置项时，自动创建一份以页面当前名称命名的设计规范文档。
- 每个符合条件的配置项对应一条自动管理的规范条目；条目引用该页面配置项，标题取配置项标题，Markdown 说明为空。
- 配置项新增、删除，或在图片/动效与其他类型之间切换时，自动条目随之新增或删除。
- 页面改名时，自动文档标题同步为新的“{页面名}设计规范”。

不处理项目级配置项、AI 上下文集成或已有手工条目的自动迁移。

## 方案

自动文档记录稳定的页面归属 `pageId`，自动条目记录稳定的来源 `fieldKey`。同步流程以这些标识而非可编辑标题做关联：

1. 页面配置 schema 保存成功后，解析该页面配置项并筛选图片、动效类型。
2. 若筛选结果非空但尚无该 `pageId` 的自动文档，创建标题为“{页面名}设计规范”的文档。
3. 将自动条目集合与符合条件的字段集合做差异同步：新增字段创建空说明条目；不存在或不再符合条件的字段删除对应自动条目。
4. 用户手工创建的文档和条目不带自动来源标记，不参与删除同步。
5. 当字段全部不再符合条件时，保留文档，但移除所有自动条目；这样文档可以继续承载用户手工补充。

若用户删除自动文档，下一次该页面保存且仍有符合条件配置时，系统会根据页面标识重新创建它。

## 数据与兼容性

在现有设计规范文档和条目数据中增加可选的自动管理元数据，不改动既有读取和手工编辑行为。页面 ID 与字段 key 是唯一关联依据；页面名只用于展示和文档标题。

## 验证

- 首次新增图片/动效字段会创建页面设计规范文档和对应条目。
- 后续新增符合条件字段会追加一条条目。
- 字段改为其他类型或被删除时，只移除关联的自动条目。
- 手工条目不会被同步过程删除。
- 页面改名会更新自动文档标题。
