# 预览与配置 - 架构设计

> 版本：v3.1更新日期：2026-08-26

## 一、入口边界

使用端存在两类 viewer shell，它们共享预览组件，但数据来源和宿主职责不同：

| 入口 | 数据来源 | 用途 |
| :-- | :-- | :-- |
| 独立 viewer-site | 发布索引、`project.json` 和发布资源目录 | 面向最终使用者的项目浏览 |
| author-site 嵌入 viewer | `/api/viewer/[projectId]/data` 与当前工作区 | iframe 嵌入、发布前或集成场景 |

独立 viewer-site 的 catch-all 页面直接挂载 `ViewerApp`，不是再嵌套 author-site iframe。`ViewerApp` 负责项目目录、页面管理入口、配置面板和 AI 问答；中央预览区使用共享 `PreviewStage`。

author-site 的项目级嵌入 viewer 同样使用 `PreviewStage`，单页嵌入 viewer 使用 `SinglePagePreview`。它们继续处理 URL 参数和 `postMessage`，不会把通信职责下沉到共享组件。

## 二、发布数据流

独立 viewer-site 先读取项目索引，再按项目 ID 读取发布清单、页面 Schema、共享配置运行值、画布状态和页面运行时资源。页面数据在宿主中整理为同一份 `PreviewStagePage` 列表，同时驱动单页与画布。

发布清单为每页携带完整 presentation，并与各页 Schema 并发加载。viewer 必须使用发布与创作端共享的 resolver，不从发布 iframe 大小、原型 meta 或画布卡片反推视口。单页 Schema 失败只让该页配置回退到项目级默认值，不更改发布 presentation，也不阻断其它页面。每次项目加载都持有独立 generation，旧请求不得更新新项目。

浏览端适配器对历史发布包保留一次性迁移：当页面缺少 `presentation` 但仍携带合法的旧 `previewSize` 时，将其转换为统一 presentation 后再交给共享舞台；新发布包始终以 `presentation` 为准。该迁移只发生在 viewer 发布数据边界，不改变共享 resolver 对历史字段的严格协议约束。

知识库文档在发布时随项目一起导出：发布流程把工作区 `knowledge/` 目录（manifest 与各 Markdown 文件）整体复制到发布产物 `knowledge/`，并把 manifest 元数据写入 `project.json` 的 `knowledge` 字段。独立 viewer-site 直接读取 `/data/{projectId}/knowledge/` 下的 manifest 和文档内容，无需登录或鉴权。

设计规范同样随发布产物导出。浏览端先从 `project.json` 读取规范目录，再按需读取各规范正文并展开其配置项绑定。绑定数据传入共享 `PageConfigPanel` 后，由表单在有非空规范的字段标题旁提供“规范”入口；入口打开配置栏左侧的内容自适应气泡，不再把关联规范聚合到“资源规范”区块，也不启用区块定位 Tab。

页面资源规范仍来自页面自身的 requirements 内容，与设计规范保持数据和展示边界。有 requirements 时，它在配置面板中作为独立可折叠区展示；为空时整个区块不挂载。

资源规范正文通过共享的 Markdown 展示组件输出语义化 HTML，并由组件自身携带排版样式，避免浏览端依赖创作端全局样式。嵌入在设计规范条目或关联规范气泡中的只读说明使用内容自适应模式，不创建自身滚动容器，统一由文档展示区或气泡正文区滚动。设计规范由项目作者维护，展示时允许 HTTPS 图片；平台图床的相对 `/api/images/*` 地址须通过浏览端数据源基址解析，确保跨站部署仍能显示图片；其它备注展示仍保持仅同源媒体的限制。

发布页面的 renderer 选择顺序固定：

1. 有 `iframeHtmlPath` 时转换为发布 iframe URL并优先使用；
2. HTML/CSS 原型页使用发布 HTML、CSS 和 meta；
3. sandbox HTML 不读取公开源码，先向服务端动态申请短时执行票据，再由独立 origin 的 `allow-scripts` iframe 加载；
4. 草图页使用序列化的 scene 和 meta；
5. 高保真页缺少 iframe 路径时，才把 `compiledJsPath` 转换为模块 URL并交给 preview shell；
6. 没有可用来源时显示空内容，不伪造其它运行时。

发布 iframe 优先保证页面脚本、依赖、样式和静态资源都按同一个发布基址解析。编译模块回退保留给缺少 iframe 路径的发布数据，不改变新发布产物的主路径。

## 三、共享预览舞台

`PreviewStage` 组合受控模式切换、默认单页预览与现有画布。宿主负责活动页、模式和画布状态，并保留左侧目录与右侧配置面板。视图模式切换由浏览端 Header 栏中间触发，与创作端共用 `PreviewModeSwitcher`。单页和画布始终可切换；文档入口只在发布清单含有至少一项非系统知识文档或至少一份设计规范时加入，避免进入空目录。浏览端 Header 使用三栏网格布局：左栏返回与项目名、中栏视图切换器、右栏登录/退出，页眉高度为 `h-14`。

单页和画布消费同一份规范化页面数据。presentation 同时决定默认 viewport 与 fixed/content 高度行为：固定画板忽略 runtime 扩高，响应式页保留视口宽度并允许内容向下扩展。runtime renderer 与展示 profile 分别解析，不再由不同入口维护尺寸分支。具体共享规则见 [创作端共享组件架构](../../../创作端/04-配置与预览/技术/05_共享组件架构设计.md)。

画布使用 `viewer` 交互模式。使用者可以平移、缩放、适应屏幕和重置视图，但页面布局编辑、素材节点创建、自动排版等创作能力仍只在创作端开放。

viewer 首屏等待画布容器与布局可用后执行一次适应屏幕。该动作只调整当前浏览器中的视口，不改写发布布局，也不会在用户后续操作时反复覆盖视口。

浏览端画布是只读布局：页面运行时上报的内容尺寸只用于创作端布局测量，不能在 `viewer` 交互模式下写回页面布局。这样可以避免发布页面加载期间的尺寸微调触发布局签名变化，重新覆盖使用者已经进行的缩放或平移。

单页模式由共享舞台监听左右方向键。默认情况下，它按已规范化的页面顺序请求宿主切换活动页；创作端编辑器提供自己的前后处理器，使键盘与标题两侧按钮共用页面、文档与边界判断。输入框、下拉框和可编辑文本区域保留方向键自身的编辑行为。

## 四、单页运行时

`SinglePagePreview` 提供统一的滚动容器、空状态、设计尺寸和 runtime 分发：

| 页面类型            | renderer                             |
| :------------------ | :----------------------------------- |
| 发布高保真页        | `IframePreviewFrame`                 |
| HTML/CSS 原型页     | `PrototypePagePreview`               |
| sandbox HTML 交互页 | `SandboxedHtmlFrame`（动态执行票据） |
| 草图页              | `SketchPagePreview`                  |
| 编译模块回退        | `PreviewPanel`                       |

使用端不额外添加设备外框。发布 iframe、原型、草图和编译模块使用相同的居中与尺寸语义，避免单页和画布对同一页面得出不同尺寸。

author-site 单页嵌入 viewer 在高保真 renderer props 中继续传入应用状态、路由参数和动作回调。页面通过应用图触发切页时，宿主更新活动页与浏览器 URL，再把新运行时状态交给目标页。

## 五、配置协作

`PageConfigPanel` 继续由宿主管理。加载项目时，每页配置按“项目级 Schema 默认值、页面级 Schema 默认值、发布共享运行值”合并；发布共享运行值可以覆盖同名页面默认值。

共享面板直接渲染共享/本页表单，不创建“配置项”标题或整体折叠状态。操作入口是滚动区外的右下角悬浮层；`ViewerApp` 只提供会话级恢复回调，因此浏览端的更多菜单不会出现字段新增项。

使用者在配置面板中的调整只保留在当前浏览器会话，不回写发布产物。配置变化更新页面对应的 `configData`，同一份规范化页面数据随即交给单页或画布 renderer：

- 发布 iframe 接收 `UPDATE_CONFIG`；
- 高保真 preview shell 更新组件 props；
- HTML/CSS 原型页重新应用 Shadow DOM 配置绑定；
- 草图页接收当前配置数据。
- sandbox HTML 不接收 React 专用 `UPDATE_CONFIG` 或任意 host action；需要新内容时重新申请执行票据。未配置独立 sandbox origin 时，发布和嵌入端 fail-closed。

图片配置在没有创作 Session 时读取为浏览器本地 Data URL，不开放匿名持久化。发布资源路径按当前数据基址解析，保证配置缩略图与页面内资源指向同一发布源。

## 六、文档视图

独立 viewer-site 在 `previewMode === "document"` 时渲染 `ViewerDocumentView`，替代中央预览区（不渲染 `PreviewStage`、左侧页面目录与右侧配置面板）。该组件是纯只读视图：

- 目录区展示发布清单 `project.knowledge` 中 `source != "system"` 的用户文档，按标题排序，不含 AI 记忆、项目公约与对话文件；只有这些用户文档或设计规范至少存在一项时，页眉才显示文档入口；
- 知识库正文使用共享 `DocumentEditor`（demo-ui）的 `readOnly` 模式渲染 Markdown；设计规范条目说明使用共享 `PageRequirements` 语义化展示组件，不挂载编辑器或创建自身滚动容器；
- 文档正文通过 `/data/{projectId}/knowledge/{fileName}` 按当前数据基址读取。

运行数据流：`ProjectPreviewPage` 从 `project.json` 拿到 `knowledge`、设计规范目录、项目级 Schema 和各页 Schema，交给 `ViewerDocumentView`。选择文档后按需拉取正文并缓存于组件状态；选择设计规范后，组件以与创作端相同的条目卡片结构重建配置项素材池，展示关联字段的缩略图、格式和尺寸。条目说明由 `PageRequirements` 输出已清洗的语义化 HTML，完整展开并交给文档展示区滚动；浏览端不提供改名、拖拽、绑定或删除入口。

## 七、发布运行时

发布流程为高保真页面生成 `compiled.js` 与 `iframe.html`，并把 React、图标、动画和 Tailwind 等运行时复制到项目自己的 `preview-runtime` 目录；sandbox 页面只写入不含源码的公开 manifest 摘要，源码保存在服务端私有源。`PreviewStage` 只选择 renderer，不生成或替换这些发布文件。

发布数据基址由 `NEXT_PUBLIC_DATA_BASE` 控制。生产环境未显式配置时使用同源 `/data`；本地 viewer-site 默认可读取 author-site 暴露的发布数据目录。

发布协议继续保留 `iframe.html`、`cssImports`、模块 cache bust 和项目内同源 runtime。相关生成规则见 [创作端动态编译方案](../../../创作端/04-配置与预览/技术/01_动态编译方案.md)。

## 八、画布资源调度

viewer 画布复用共享调度器。小项目直接使用实时页面；页面数量达到调度阈值后，才启用截图和 iframe 预算策略。截图只是一种性能占位，不能覆盖比它更新的实时页面。

页面卡片继续保留以下边界：

- 当前版本截图可在 iframe 加载期间显示；
- 没有有效截图时回退实时 renderer；
- iframe 可按可见性进入休眠；
- 原型与草图保留轻量直接渲染；
- sandbox 页面使用短时动态票据和 `allow-scripts` iframe，画布不保留长期可执行 iframe；
- 画布页面内容不可直接操作，交互由画布视口接管。

截图完整规则见 [截图服务与预览快照机制](../../../创作端/04-配置与预览/技术/07_截图服务与预览快照机制.md)。

## 九、错误边界

- 发布索引或项目清单失败：由 `ViewerApp` 的加载/错误状态处理；
- 单页 Schema 失败：该页回退项目级默认配置，其它页面继续完成并发初始化；
- 项目切换期间旧请求返回：由加载 generation 丢弃，不得覆盖当前项目或加载态；
- 发布 iframe 内部脚本错误：当前外层只能感知 iframe 加载与尺寸消息，不能虚构运行时错误捕获；
- sandbox ticket 过期、独立 origin 未配置或私有 manifest 不一致：拒绝加载并显示明确的运行时错误，不回退到公开源码 URL；sandbox 的隔离不承诺绝对断网或 CPU/内存硬隔离；
- 评论层与发布 iframe 之间只通过 `postMessage` 传递点击、滚动和视口尺寸；发布 iframe 可能跨源，宿主不得读取其 `contentWindow` 的窗口属性，坐标计算使用消息中的 `viewportWidth`；
- 编译模块失败：沿用 `PreviewPanel` 的请求终态和错误展示；
- 活动页不存在：共享舞台保留受控状态并显示空单页，宿主决定是否切换到其它页面；
- author-site 嵌入端点不可达：由外层 iframe 宿主展示连接错误。
