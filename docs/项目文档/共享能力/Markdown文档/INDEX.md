# Markdown 文档与编辑器

> 更新日期：2026-09-10

整项目引用支持项目下拉「插入」文字按钮和选定范围后的独立入口；Agent 按权限读取引用的业务要求见[能力需求](./Markdown编辑器_需求文档.md)，读取链路见[引用协议](../../创作端/09-知识库/技术/03_项目页面文档引用与双向链接.md)。

本专题是项目 Markdown 编辑器公共能力的唯一文档入口。编辑器基于 **Milkdown Crepe v7**，由 `@workbench/demo-ui` 提供，供创作端和使用端的多个宿主复用。创作端文档保存由宿主复用统一协调器：保存失败会暂停自动提交并保留可恢复草稿，状态与恢复边界见[宿主接入、保存边界与测试](./技术/04_宿主接入、保存边界与测试.md)。

正常自动保存不持续占用编辑区，也不反复播报 `dirty/saving/saved` 状态；只有需要用户处理的保存异常才显示状态条。

头部单行工具栏与 `···` 自适应收纳见[核心架构](./技术/01_核心架构与Crepe适配.md)。

项目内容引用的跨项目选择、双 Tab 目录、行内链接、引用末尾普通输入边界、完整悬停热区与来源浮层，以及普通链接预览隔离见[扩展与渲染适配](./技术/03_扩展与渲染适配.md)，业务边界见[能力需求](./Markdown编辑器_需求文档.md#5-项目内容引用)。
