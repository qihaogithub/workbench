# Markdown 文档与编辑器

> 更新日期：2026-09-07

本专题是项目 Markdown 编辑器公共能力的唯一文档入口。编辑器基于 **Milkdown Crepe v7**，由 `@workbench/demo-ui` 提供，供创作端和使用端的多个宿主复用。

标题菜单统一主题、列表项原子转换与选区快照校验见[核心架构](./技术/01_核心架构与Crepe适配.md)，产品语义见[标题样式转换](./Markdown编辑器_需求文档.md#标题样式转换)。

跨文档身份隔离与菜单无正文副作用的契约见[宿主接入与测试](./技术/04_宿主接入、保存边界与测试.md)；流式/内滚动宿主的可视裁剪边界见[核心架构](./技术/01_核心架构与Crepe适配.md)。
