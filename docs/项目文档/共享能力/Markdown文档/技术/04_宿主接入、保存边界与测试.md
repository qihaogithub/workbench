# Markdown 编辑器宿主接入、保存边界与测试

## 一、公共接入契约

共享编辑器只暴露内容和行为回调。当前公共接口包括：

| 参数 | 职责 |
|:-----|:-----|
| `value` / `onChange` | 受控 Markdown 正文及本地变更通知 |
| `documentKey` | 稳定资源身份；切换时隔离菜单、选区、撤销历史与异步回调 |
| `readOnly` / `placeholder` | 编辑状态和文档级占位提示 |
| `uploadHandler` | 图片、附件或视频的宿主资源处理 |
| `referenceCandidates` / `referenceContext` | 宿主提供的候选项和稳定来源上下文 |
| `className` | 宿主布局和外层样式接入 |

编辑器不接收 `workingDir`、绝对路径、普通 Session token 或内部授权对象。内部的 overlay root、浮层定位器和块菜单类型不对外暴露。可切换文档的宿主应传入稳定 `documentKey`（不能使用正文或保存版本号）；省略时使用 `referenceContext.source` 的序列化身份，无来源上下文的单文档输入框沿用挂载生命周期。已有资源级 React key 的宿主也满足身份隔离约束。

## 二、宿主职责

宿主负责：

- 根据业务身份读取正文并决定 `value`；
- 根据角色决定 `readOnly` 和可用扩展；
- 在 `onChange` 后维护脏状态、协同草稿和保存队列；
- 在切换文档或卸载前 flush 未提交内容；
- 处理引用点击、图片上传、评论、历史和错误提示。

知识库文档使用项目子资源 API 和 `projectId + documentId` 定位；项目/页面公约、memory 等工作区文件仍由其业务入口定位。自动保存、Authority receipt、协同 flush 和资源版本分别由[知识库架构](../../../创作端/09-知识库/技术/01_知识库架构设计.md)与[实时保存与协同编辑](../../../创作端/03-项目管理/技术/11_实时保存与协同编辑.md)维护。

## 三、测试门禁

`@workbench/demo-ui` 至少覆盖：

- Markdown 往返幂等；
- `DocumentEditor` 集成渲染与受控更新；
- 中文标题选择器和原生 TopBar 换行；
- TopBar 的标题转换与手柄插入复用菜单组件，但前者不得插入空段或清除当前正文；
- 编辑器级浮层定位策略：首行选区避让 TopBar、底部翻转/侧移、无安全位置隐藏、块菜单不与当前块相交；
- 块菜单的不透明表面、编辑器边界内定位、固定最大高度、顶部 Tab 分组和分组内容独立滚动；
- 单一块手柄的点击、`Enter`、`Space`、原生拖拽互不冲突，列表标记/手柄/正文几何对齐；
- 真实 Milkdown 集成：Markdown 更新、标题/格式命令、评论入口、上传引用、只读态、批注编辑器和 StrictMode 重挂载；
- 打开/取消菜单不改变正文、onChange 与 history；结构节点插入可一次撤销；普通事务不重置分组；斜杠输入不丢焦点，Escape 后不因选区更新立即重开；正文相同的跨文档切换也关闭旧菜单并隔离 history；
- Crepe Frame 主题 token、工具栏三态、滚动边界和选中状态；
- 图片远程粘贴与本地化失败降级。

浏览器回归需覆盖首行选中文字、点击首行手柄、长段落、多行列表、编辑器底部、窄窗口、移动尺寸和滚动前后定位。验收以元素矩形相交检测确认：工具栏不覆盖选区、菜单不覆盖当前块、正文文字保持可见。

author-site 因 Milkdown 为 ESM-only，使用 `jest-milkdown-mock.js` 映射 `@milkdown/*`。业务宿主另行覆盖文档切换、自动保存、协同回写、只读展示和权限边界。

## 四、Milkdown 补丁与升级

`patches/@milkdown__components@7.22.0.patch` 为项目级图片尺寸编解码补丁。升级 Milkdown 或 `@milkdown/components` 时必须同时复核：

1. 图片块 Markdown 编解码和目标宽度元数据；
2. 容器最大宽度与窄屏临时缩放；
3. ImageBlock 上传回调和远程图片粘贴；
4. Crepe TopBar、公开 Provider 生命周期、浮层安全定位、表格选中和主题 token 回归。

升级完成后先运行 `corepack pnpm check:demo-ui`，再运行 `corepack pnpm check:repo` 检查文档链接和仓库契约。

浮层避让属于 `demo-ui` 内部 feature 与 `@floating-ui/dom` 的正式实现，不得通过新增 Milkdown patch、`MutationObserver` 查找/改写控件、隐藏原生控件转发事件或合成 PointerEvent；也不得把 `z-index` 或 CSS transform 当作碰撞解决手段。
