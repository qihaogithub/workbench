# Markdown 编辑器宿主接入、保存边界与测试

## 一、公共接入契约

共享编辑器只暴露内容和行为回调。当前公共接口包括：

| 参数 | 职责 |
|:-----|:-----|
| `value` / `onChange` | 受控 Markdown 正文及本地变更通知 |
| `readOnly` / `placeholder` | 编辑状态和文档级占位提示 |
| `uploadHandler` | 图片、附件或视频的宿主资源处理 |
| `referenceCandidates` / `referenceContext` | 宿主提供的候选项和稳定来源上下文 |
| `className` | 宿主布局和外层样式接入 |

编辑器不接收 `workingDir`、绝对路径、普通 Session token 或内部授权对象。

## 二、宿主职责

宿主负责：

- 根据业务身份读取正文并决定 `value`；
- 根据角色决定 `readOnly` 和可用扩展；
- 在 `onChange` 后把最新值交给统一保存协调器，维护脏状态、单请求队列和本地草稿；
- 在切换文档或卸载前 flush 当前资源；协调器只等待当前请求结束，不绕过 Authority 直接写文件；
- 处理引用点击、图片上传、评论、历史和错误提示。

保存协调器将状态固定为 `clean`、`dirty`、`saving`、`saved`、`offline`、`authority-degraded`、`conflict`、`permission-denied` 和 `validation-failed`。成功响应（含 Authority receipt 或明确的 API 成功响应）确认后才清理本地草稿；网络失败、Authority 备份缺失、外部漂移、资源冲突、权限失败和校验失败分别保留待提交值并进入对应状态。收到 `DOCUMENT_AUTHORITY_BACKUP_MISSING` 或底层 `WORKSPACE_AUTHORITY_BACKUP_MISSING` 后，必须暂停该资源的自动保存，不能无限重试，也不能在前端静默执行 reconcile-adopt；状态条提供显式「重试保存」和「放弃本地草稿」。基线变化进入冲突时，必须由用户明确选择「恢复本地草稿」或「放弃本地草稿」，不得自动覆盖服务端内容。Authority 恢复由运维 status/preflight 和显式 reconcile-adopt/restore 流程负责，完成后用户主动重试或重新加载。

具备 `projectId + workspaceId` 的宿主通过 `workspace-offline-drafts` 将值、资源路径和服务端基准指纹写入 IndexedDB。每次成功提交都会把已提交内容及 receipt revision 推进为新基准；如果请求在途中已产生更新的本地编辑，协调器会用新基准重写该草稿，避免重新打开时误报冲突。重新打开时只有基准指纹一致才恢复草稿；服务端内容变化进入冲突状态，不自动覆盖任一版本。IndexedDB 不可用时降级为普通服务端编辑，不把内存值标记为已持久化。本地指纹仅用于浏览器草稿基线比较，不替代 Authority 的 revision、rootHash 或服务端哈希。

知识库文档使用项目子资源 API 和 `projectId + documentId` 定位；项目/页面公约、memory 等工作区文件仍由其业务入口定位。自动保存、Authority receipt、协同 flush 和资源版本分别由[知识库架构](../../../创作端/09-知识库/技术/01_知识库架构设计.md)与[实时保存与协同编辑](../../../创作端/03-项目管理/技术/11_实时保存与协同编辑.md)维护。

## 三、测试门禁

`@workbench/demo-ui` 至少覆盖：

- Markdown 往返幂等；
- `DocumentEditor` 集成渲染与受控更新；
- Crepe 异步初始化期间的受控 `value` 更新竞态；
- 中文标题选择器；
- TopBar 溢出控制器；
- Crepe Frame 主题 token、工具栏三态、滚动边界和选中状态；
- 图片远程粘贴与本地化失败降级。

author-site 因 Milkdown 为 ESM-only，使用 `jest-milkdown-mock.js` 映射 `@milkdown/*`。业务宿主另行覆盖文档切换、自动保存、协同回写、只读展示和权限边界；保存协调器还需覆盖成功后清理草稿、提交在途时的草稿基准推进、失败暂停与显式重试、同基准草稿恢复、基准变化冲突、IndexedDB 不可用降级，以及 Authority 备份缺失时的结构化错误透传、中文提示和本地正文保留。普通文档视图和设计规范编辑器的保存回归必须同时通过，不能只测共享组件。

## 四、Milkdown 补丁与升级

`patches/@milkdown__components@7.22.0.patch` 为项目级图片尺寸编解码补丁。升级 Milkdown 或 `@milkdown/components` 时必须同时复核：

1. 图片块 Markdown 编解码和目标宽度元数据；
2. 容器最大宽度与窄屏临时缩放；
3. ImageBlock 上传回调和远程图片粘贴；
4. Crepe TopBar、表格选中和主题 token 回归。

升级完成后先运行 `corepack pnpm check:demo-ui`，再运行 `corepack pnpm check:repo` 检查文档链接和仓库契约。
