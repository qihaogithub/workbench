# 页面高保真快照导出需求文档

> 更新日期：2026-08-20

## 模块定位

页面高保真快照导出服务于外部网页和开发项目的 Agent 协作。用户可以把已经登录、滚动、展开并调整到目标状态的当前浏览器页面，保存为一个可阅读、可修改、可本地预览的网页工程。

该能力与创作端静态原型导入并列但不混用。高保真快照保留可执行内容，不直接进入创作端原型页运行时；需要画布评审时，应从原始快照另行生成满足静态安全规则的派生副本。

## 目标用户

- 需要把线上页面状态交给编码代理分析和修改的开发者。
- 需要保存登录后页面、展开状态或运行时表单值的设计和产品人员。
- 需要对比原页面与修改工程、追踪缺失资源和交互风险的评审人员。

## 功能需求

### 当前标签捕获

用户可以在目标页面准备好状态后，显式捕获当前活动标签。捕获不得静默读取其他标签、浏览历史、Cookie 数据库或浏览器存储数据库。

用户可以填写路由标识、来源项目标识和页面状态备注，使 Agent 能把快照映射回原开发项目。

### 忠实基线与可编辑工程

导出结果同时包含不可覆盖的忠实基线和供 Agent 修改的工作区。脚本、内联事件、表单目标、iframe 描述、开放 Shadow DOM、当前表单值和可读取的画布像素应尽量保留。

工作区需要把页面入口、样式、脚本、frame、资产和可恢复源码组织成可导航文件，同时保持原执行顺序和关键执行属性。没有真实源码映射时，不能把格式化后的构建产物宣称为原始源码。

### 报告与 Agent 入口

导出结果需要提供统一清单、依赖关系、采集完整性、可读性、还原度和安全报告。Agent 只读入口说明和依赖关系即可判断应该修改哪些第一方文件、哪些目录不可覆盖，以及如何运行隔离预览。

无法捕获的跨域资源、运行时后端依赖和不可序列化状态必须明确列出，不能以“交互正常”笼统代替逐项结论。

### 安全预览

快照包含不受信任的可执行内容，默认预览必须离线，并限制写请求、下载、弹窗和顶层导航。访问真实网络必须由用户显式选择，并提示可能触发真实后端操作。

### 下载与取消

大页面捕获需要显示阶段和进度，支持取消并清理临时数据。浏览器后台被回收后，任务状态仍应可查询，不应因为单条大消息超过限制而丢失整个页面。

下载前必须展示安全与保真摘要并由用户再次确认。产品化界面可以在用户按需授权后列出 HTTP/HTTPS 标签，由用户逐项选择并串行捕获；不得默认全选、静默切换标签或把非活动标签截图冒充目标页面。

用户可以选择高保真或紧凑评审 profile，并为 exact origin 保存默认规则。扩展历史只保存捕获标识、URL、route、时间、文件名和终态，不保存页面内容。解压后的工程需要提供内容哈希修改历史和本地再打包能力。

## 业务规则与约束

- 单页只处理用户显式调用的当前标签；批量模式只处理用户逐项勾选并已授权 exact origin 的标签。
- 高保真快照是可执行工程，不是静态原型页，不能绕过创作端原型安全规则直接导入。
- 忠实基线只用于对照和回退，Agent 默认只修改工作区。
- DOM 和脚本中已经出现的令牌或个人信息可能进入导出包，下载前必须提示并生成安全报告。
- 不承诺恢复组件源码、类型源码、构建配置、闭包、内存状态、WebSocket、Service Worker 或浏览器数据库。
- 对外分发前必须完成采集引擎许可决策；许可未完成时仅限内部技术原型。

## 验收标准

- 用户可以从当前 HTTP/HTTPS 标签生成结构完整的高保真快照 ZIP。
- 快照保留脚本、事件、iframe、表单状态、开放 Shadow DOM 和可读取画布的代表性夹具验证通过。
- 10MB 和 50MB 页面数据可以分块校验、乱序重组，损坏或缺块会失败。
- 忠实基线、可编辑工作区、Agent 入口、统一清单和五类报告齐全。
- 默认权限不包含 Cookie、浏览历史或永久全站读取权限。
- 默认本地预览不连接真实后端；真实网络模式有明确风险提示。
- 下载前必须经过安全/保真摘要审核；拒绝或取消会清理待下载内存数据。
- 对外发布、商店上架和安装包分发在许可评审完成前被明确禁止。
