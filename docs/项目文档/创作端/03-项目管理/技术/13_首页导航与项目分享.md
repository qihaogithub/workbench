# 首页导航与项目分享 - 实现设计

> 版本：v1.0
> 更新日期：2026-08-05

## 一、背景

创作端首页是用户进入项目管理的主入口。顶部导航在既有「Figma 插件」「CLI」「设置」的基础上新增「浏览端」入口，方便创作者随时跳转到使用端 FlowSite 浏览已发布内容；项目卡片更多菜单新增「分享」入口，把编辑页顶部的分享能力下沉到首页，让用户不必进入编辑页即可复制编辑链接或获取浏览链接。

## 二、浏览端基址解析

首页「浏览端」按钮、分享弹窗的浏览链接共用同一个浏览端基址解析规则，实现在 `packages/author-site/src/lib/viewer-url.ts`：

1. 优先读取 `NEXT_PUBLIC_VIEWER_URL` 环境变量，该变量是浏览端的完整基址（本地 dev 或 Docker 部署时由环境配置注入）。
2. 未配置时按当前创作端地址推导：本地 dev（创作端 4200）推导到浏览端 4300，Docker 部署（创作端 3200）推导到浏览端 3300，主机名与协议保持一致。
3. 无法推导（如生产环境无端口号）时返回空串，调用方降级处理：首页「浏览端」按钮会提示未配置浏览端地址，分享弹窗则回退为相对路径。

该规则同时服务两处调用方，避免出现多处维护导致地址分叉。相关环境变量说明见 [Docker 部署方案](../06-基础设施/技术/03_Docker部署方案.md) 的环境变量表。

## 三、首页顶部导航

首页 header 右侧按钮顺序为：「Figma 插件」「浏览端」「CLI」「设置」。

- 「浏览端」为普通按钮而非链接：点击后按上述基址规则取地址，用新窗口打开浏览端首页（使用端项目列表页），并设置 `noopener,noreferrer` 隔离新窗口的 window 引用。
- 基址为空时不会打开新窗口，改为提示「未配置浏览端地址」。

## 四、项目卡片分享入口

项目卡片更多菜单新增「分享」项（普通项目与模板卡片均显示），点击后打开与编辑页共用的分享弹窗 `ShareDialog`。

分享弹窗提供两个标签页：

- **编辑链接**：`创作端地址 + /demo/{项目id}/edit`，打开即复制。
- **浏览链接**：先查询发布状态；已发布直接展示浏览端链接，未发布则提示先发布，发布成功后才展示链接。

发布状态查询与发布动作复用既有项目发布接口，分享弹窗本身不引入新的后端能力，详见编辑页分享弹窗的实现文件 `packages/author-site/src/components/share/ShareDialog.tsx`。

复制链接的安全上下文处理：在 HTTPS 或 localhost 下使用 `navigator.clipboard.writeText`；在 HTTP 局域网访问（非安全上下文）下退化为 `document.execCommand('copy')`。`execCommand` 必须选中弹窗内已渲染、处于 Dialog 焦点范围内的链接输入框来执行，而不是新建并聚焦一个挂在 `document.body` 下的临时文本框——否则会被弹窗的焦点陷阱抢回焦点导致复制静默失败。实现会检查 `execCommand` 的返回值，失败时提示「复制失败，请手动复制」，避免误报已复制。

## 五、首页卡片导航

项目卡片主区域使用 `next/link` 的 `<Link>` 指向编辑页 `/demo/{项目id}/edit`，走客户端导航与预取，避免整页刷新。编辑页路由自带 `loading.tsx`（`/demo/[id]/edit/loading.tsx`），进入时显示加载占位，减少白屏等待。
