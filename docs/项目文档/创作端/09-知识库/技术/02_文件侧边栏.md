# 文件侧边栏与文档视图

项目编辑页左侧的「代码」栏是用户在编辑页浏览和管理项目文件的入口。它只保留代码视图（`WorkspaceFileTree`），不再拆分「文档 / 代码」子视图。

原「文档」栏中的知识库文档列表（`KnowledgePanel`）迁移到预览区新增的「文档」视图下，作为中间栏左侧的目录使用。

## 一、代码栏

`WorkspaceFileTree` 递归渲染工作空间文件树，支持懒加载子目录、展开/折叠。根目录由 `/api/sessions/:sessionId/workspace/files` 返回。

当项目存在聊天附件时，根目录会注入一个名为「聊天文件」的虚拟目录（`.ai-attachments/`），其子项为各附件。点击文本附件走附件读取接口查看内容；点击图片附件会打开原始图片。

## 二、文档视图

「文档」视图是预览区的一种视图模式（单页 / 画布 / 文档），通过 Header 栏中间的视图切换进入。`DocumentView` 组件自上而下包含：

- **目录区（左 1/4）**：列出项目知识库用户文档（`knowledge/manifest.json` 中 `source !== "system"` 的条目），支持切换文档、查看历史、新建文档。
- **文档编辑区（右 3/4）**：加载选中文档的 Markdown 内容，使用 `DocumentEditor` 就地编辑，编辑后通过「保存」按钮写回 `/api/knowledge/{id}`。

### 数据刷新机制

- 知识库变动：`knowledge-updated` 窗口事件 → 文档视图 `fetchItems()`。
- 聊天附件变动：`chat-attachments-updated` 窗口事件 → 代码栏重新加载根目录。
- 事件由 `chat-input.tsx` 在上传成功后、以及相关批量操作后广播。

原 `KnowledgePanel` 的「AI 记忆」「项目公约」「对话文件」「批量删除」等能力随文档列表一并迁移，其中对话文件仍可在代码栏的「聊天文件」虚拟目录中查看。
