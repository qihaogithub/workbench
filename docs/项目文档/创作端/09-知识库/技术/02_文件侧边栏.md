# 文件侧边栏与文档视图

项目编辑页左侧的「代码」栏是用户在编辑页浏览和管理项目文件的入口。它只保留代码视图（`WorkspaceFileTree`），不再拆分「文档 / 代码」子视图。

原「文档」栏中的知识库文档列表（`KnowledgePanel`）迁移到预览区新增的「文档」视图下，作为中间栏左侧的目录使用。

## 一、代码栏

`WorkspaceFileTree` 递归渲染工作空间文件树，支持懒加载子目录、展开/折叠。根目录由 `/api/sessions/:sessionId/workspace/files` 返回。

当项目存在聊天附件时，根目录会注入一个名为「聊天文件」的虚拟目录（`.ai-attachments/`），其子项为各附件。点击文本附件走附件读取接口查看内容；点击图片附件会打开原始图片。

## 二、文档视图

「文档」视图是预览区的一种视图模式（单页 / 画布 / 文档），通过 Header 栏中间的视图切换进入。`DocumentView` 组件自上而下包含：

- **目录区（左 1/4）**：复刻原左侧栏 `KnowledgePanel` 的文档列表结构，自顶向下为：
  - **AI 记忆**：列表项（Brain 图标），点击在右侧编辑器内打开并编辑 `memory.md`。
  - **项目公约**（可折叠文件夹，amber FolderOpen 图标）：内含项目公约（根，`convention.md`）与各页面公约（`demos/{pageId}/convention.md`）子项，点击在右侧编辑器内打开编辑。悬停文件夹显示加号，点击加号弹出菜单可选择「项目公约」或「页面公约」；选择「页面公约」再弹窗选择具体页面。
  - **项目知识库**：可折叠列表，列出用户文档（`knowledge/manifest.json` 中 `source !== "system"` 的条目），支持切换文档；每项 hover 显示眼睛/编辑图标与「更多」菜单（编辑、历史、删除），可新建文档。
  - **对话文件**：可折叠列表，列出当前会话聊天附件（`/api/sessions/:sessionId/attachments`），点击查看内容或打开图片；每项「更多」菜单支持查看、转为知识库、删除。
- **文档编辑区（右 3/4）**：加载当前目标（知识库文档 / AI 记忆 / 项目公约 / 页面公约）的 Markdown 内容，使用 `DocumentEditor` 就地编辑后通过「保存」按钮写回。知识库文档走 `/api/knowledge/{id}`，其余分别走 workspace files 接口的 `memory.md` / `convention.md` / `demos/{pageId}/convention.md`。

`DocumentView` 通过 `onChatFileSelect` / `onChatFileConvert` / `onChatFileDelete` / `onDocDeleted` 将对话文件的打开/转换/删除动作委托给编辑页处理（复用附件查看与知识库转换逻辑）。AI 记忆与项目公约不再弹窗，由文档视图内部直接读写 workspace 文件。

### 数据刷新机制

- 知识库变动：`knowledge-updated` 窗口事件 → 文档视图 `fetchItems()`。
- 聊天附件变动：`chat-attachments-updated` 窗口事件 → 文档视图 `fetchChatFiles()`，代码栏重新加载根目录。
- 事件由 `chat-input.tsx` 在上传成功后、以及相关批量操作后广播。

原 `KnowledgePanel` 的「AI 记忆」「项目公约」「对话文件」「批量删除」等能力随文档列表一并迁移，其中对话文件仍可在代码栏的「聊天文件」虚拟目录中查看。
