# 文件侧边栏与文档视图

项目编辑页左侧的「代码」栏是用户在编辑页浏览和管理项目文件的入口。它只保留代码视图（`WorkspaceFileTree`），不再拆分「文档 / 代码」子视图。

原「文档」栏中的知识库文档列表（`KnowledgePanel`）迁移到预览区新增的「文档」视图下，作为中间栏左侧的目录使用。

## 一、代码栏

`WorkspaceFileTree` 递归渲染工作空间文件树，支持懒加载子目录、展开/折叠。根目录由 `/api/sessions/:sessionId/workspace/files` 返回。

当项目存在聊天附件时，根目录会注入一个名为「聊天文件」的虚拟目录（`.ai-attachments/`），其子项为各附件。点击文本附件走附件读取接口查看内容；点击图片附件会打开原始图片。

## 二、文档视图

「文档」视图是预览区的一种视图模式（单页 / 画布 / 文档），通过 Header 栏中间的视图切换进入。`DocumentView` 组件自上而下包含：

- **目录区（左 1/4）**：复刻原左侧栏 `KnowledgePanel` 的文档列表结构，自顶向下为：
  - **AI 记忆**：列表项（Brain 图标），点击在右侧编辑器内打开并编辑 `memory.md`。
  - **项目公约**（可折叠文件夹，amber FolderOpen 图标）：只展示已创建的项目公约（根，`convention.md`）与页面公约（`demos/{pageId}/convention.md`），不会在项目初始化或读取时创建文件。悬停文件夹显示加号，点击加号选择「项目公约」或「页面公约」后才创建默认模板并在右侧打开；选择页面公约前会弹窗选择具体页面。已有公约从目录直接打开，不会被覆盖；每个已创建条目在右侧提供统一的「更多」菜单，从中确认删除并经 Workspace Authority 移除。删除接口只接受这两类公约路径，并以当前文件哈希作为 mutation 预期值，防止删除前内容已被其他协作者改变时误删。
  - **项目知识库**：可折叠列表，列出用户文档（`knowledge/manifest.json` 中 `source !== "system"` 的条目），支持切换文档；每项右侧只显示统一的「更多」菜单，菜单提供资源历史和删除，不再显示眼睛或编辑快捷图标。文件夹加号打开「新建 / 上传」气泡菜单：新建立刻生成空的「未命名文档」、在右侧打开，并让左侧标题进入行内重命名；回车或失焦提交名称，Esc 放弃名称修改但保留文档。上传仅接收 `.md`、`.markdown`、`.txt`，使用文件名作为标题并直接在右侧打开。
  - **对话文件**：可折叠列表，列出当前会话聊天附件（`/api/sessions/:sessionId/attachments`），点击查看内容或打开图片；每项「更多」菜单支持查看、转为知识库、删除。
  - **设计规范**（可折叠文件夹，cyan FolderOpen 图标）：内含多份设计规范文档（`design-spec/spec-{id}.json` + `design-spec/manifest.json` 索引）。悬停文件夹点击加号新建一份设计规范文档；子项点击后，右侧通过统一的「更多」菜单删除。选中某份文档后，右侧编辑区切换为设计规范编辑器（三区：中栏规范卡片列表 + 右栏配置项素材池）。
- **文档编辑区（右 3/4）**：加载当前目标（知识库文档 / AI 记忆 / 项目公约 / 页面公约）的 Markdown 内容，使用 `DocumentEditor` 就地编辑。编辑区不另设业务标题栏与保存按钮——当前选中文档由左侧目录标示；编辑器在可编辑状态显示 Crepe 原生吸顶 TopBar，集中提供标题、文字格式、列表、引用、代码、表格等完整编辑操作，只读时隐藏 TopBar。主题沿用 Crepe Frame 的正文与控件表面层级并自适应宿主明暗模式；选区工具条使用明确的默认、悬停和选中底色，表格边框与单元格选中由 Crepe 原生规则按校准后的主题 token 渲染。块手柄保留 Crepe 原生的“添加 + 拖拽”两个入口，并统一使用紧凑尺寸。自动保存在 `markdownUpdated` 触发 `onChange` 时捕获目标与内容、调度一次 800ms 防抖写回，并在切换文档与组件卸载时冲刷未落盘编辑，避免切换/刷新丢改动。知识库文档走 `/api/knowledge/{id}`，其余分别走 workspace files 接口的 `memory.md` / `convention.md` / `demos/{pageId}/convention.md`。选中「设计规范」文档时，改用 `DesignSpecEditor`（卡片列表 + 配置项素材池），不渲染 Markdown 编辑区。

`DocumentView` 通过 `onChatFileSelect` / `onChatFileConvert` / `onChatFileDelete` / `onDocDeleted` 将对话文件的打开/转换/删除动作委托给编辑页处理（复用附件查看与知识库转换逻辑）。AI 记忆与项目公约不再弹窗，由文档视图内部直接读写 workspace 文件。

### 数据刷新机制

- 知识库变动：`knowledge-updated` 窗口事件 → 文档视图 `fetchItems()`。
- 聊天附件变动：`chat-attachments-updated` 窗口事件 → 文档视图 `fetchChatFiles()`，代码栏重新加载根目录。
- 事件由 `chat-input.tsx` 在上传成功后、以及相关批量操作后广播。

原 `KnowledgePanel` 的「AI 记忆」「项目公约」「对话文件」「批量删除」等能力随文档列表一并迁移，其中对话文件仍可在代码栏的「聊天文件」虚拟目录中查看。

### 设计规范编辑器（DesignSpecEditor）

选中「设计规范」文件夹下的某份文档后，右侧编辑区切换为 `DesignSpecEditor`（三区布局）：

- **中栏（规范卡片列表）**：每条目一张卡片，可展开/折叠、重命名、删除；展开后展示已绑定配置项表格（缩略图 + 名称 + 类型 + 来源，行末解绑）与共享 `DocumentEditor` 的 Markdown 说明编辑区。说明编辑直接使用 Crepe 的标题、格式、列表、表格等能力，不再维护独立的文本框、编辑/预览切换或局部快捷按钮。`＋` 新建条目，卡片可拖拽排序，可从右栏拖入配置项绑定。中栏不设标题栏与保存按钮——改动自动保存（`DesignSpecWorkspace` 在脏数据出现后 800ms 防抖落盘）。
- **配置项预览**：右栏素材项和中栏已绑定配置项表的每一项均支持悬停或键盘聚焦预览其所在页面示意图；图片项同时显示默认图片。预览不重复展示配置项或页面名称，鼠标离开或焦点离开即关闭。图片仍可点击进入全屏查看。
- **右栏（配置项页签）**：右侧栏为「配置项」与「评论」两个页签，选中设计规范文档时自动切到「配置项」。配置项页签聚合项目级 + 各页面级 schema 的配置项，顶部搜索框与「全部/已绑定/未绑定」过滤按钮并列，下方类型过滤 chips（色值/文字/图片/数值/动效），按来源（项目级/各页面）分组；每项展示 swatch（颜色块/文字缩写/图片缩略），可拖拽进卡片绑定。
- **数据模型**：只存“条目结构 + 说明文字 + 对配置项的引用”，不存配置值；配置值实时从 `project.config.schema.json` / 页面 `config.schema.json` 投影，规范永不过期。页面级引用按 `pageId + fieldKey`，页面删除后显示“已失效引用”灰条。

设计规范数据走 `/api/design-specs`（列表/新建/单文档/配置项池），live workspace 写入经 workspace mutation authority 提交。详见 `docs/plans/进行中/创作端-设计规范文档录入与维护-实施计划.md`。

独立浏览端发布时会携带设计规范目录及其索引；浏览端文档视图只读展示「项目知识库」和「设计规范」，不呈现创作态的 AI 记忆、公约或对话文件。
