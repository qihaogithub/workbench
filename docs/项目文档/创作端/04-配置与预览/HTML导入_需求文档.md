# HTML 导入需求

> 版本：v1.4  更新日期：2026-08-27

## 一、模块定位

HTML 导入把单个 `.html` 或 `.htm` 文档转换为创作端页面。导入前先分析页面结构、资源引用、脚本和视口信号，再决定创建为静态 HTML/CSS 原型页还是隔离的可执行 HTML 页，并让用户确认页面的默认展示视口。

导入不保证外部资源、浏览器高级能力或任意脚本业务完全可用；这些内容必须被明确提示，且不得获得创作端会话数据或宿主页面权限。

## 二、入口与导入流程

- 页面树的 HTML 上传入口、编辑页预览区域拖入，以及画布和单页面预览空白区域中粘贴 HTML 代码都支持 `.html`、`.htm` 或 `text/html` 内容。可信 Figma 导出物会直接创建页面，不展示“导入 HTML 工作台”；其他 HTML 仍交给工作台处理，普通文本和非 HTML 代码不触发导入。
- 工作台支持一次选择多个文件。文件默认以去掉扩展名的文件名作为页面名称，用户可以逐项修改名称、选择文件、移除待导入文件。
- 准备阶段读取并规范化 HTML、返回判型结果、视口推荐、兼容性提示和（可用时）安全预览；准备阶段不得创建页面或修改 Workspace。
- 只有提交阶段才创建页面。批量提交逐项处理，成功项保留，失败项保留在工作台并显示原因，便于重试；关闭工作台、移除文件、取消或草稿过期时清理未提交状态。未提交草稿保存 15 分钟，过期后不可继续提交。
- 普通 HTML 在分析完成后只进入可提交状态，仍须由用户执行一次明确的“导入”操作才会改变 Workspace。选择或拖入可信 Figma 导出物本身即视为明确导入动作，系统在完成校验后直接创建页面。
- 提交必须绑定当前用户、项目、编辑 Session 和 Workspace。Session 失效、页面或文件夹冲突、草稿不存在或校验失败时不得写入页面。

## 三、判型、提示与拒绝条件

### 3.1 判型结果

- 高置信度固定画板：仅当文档含 `.figma-export` 导出标记且能解析出有效固定宽高时，才识别为 Figma 导出物，推荐 `fixed-canvas`，使用识别尺寸和固定高度行为。
- 中置信度数字视口：识别到有效的数字 `width`、`height` 视口时，推荐 `responsive-page`，使用识别尺寸和内容高度，并要求确认。
- 低置信度响应式或未知视口：`device-width`、非数字视口、缺失视口或信号冲突时，推荐电脑 `1440×900` 的 `responsive-page`，并要求确认。
- runtime 只由可执行能力决定：脚本、事件处理器和 JavaScript URL 使用隔离运行时；普通外链/相对资源只影响兼容性结果，不能改变 runtime。
- 外链/相对资源、嵌入上下文、表单提交、Worker、弹窗和下载必须作为可展开的兼容性提示返回。每项资源提示必须说明分类、是否保留与安全的后续建议，且不展示原始 URL；除可信 Figma 导出物外，部分兼容项必须经用户明确确认后才能提交。可信 Figma 导出物仍显示提示，且受限资源仍按既有安全规则阻断，不会静默下载或放开网络。

### 3.2 可拒绝条件

分析阶段拒绝：

- 文件为空、无法解析为有效 HTML；
- UTF-8 HTML 源码超过 2 MiB；
- 单个 data URL 超过 1 MiB，或所有 data URL 合计超过 2 MiB。
- 文档既没有可见文本，也没有可识别的媒体、绘制、表单或脚本渲染入口。

静态原型在提交前还必须通过原型门禁，包括禁止脚本、内联事件、JavaScript URL、嵌入和带实际提交行为的表单。门禁失败时不得以静态成功结果创建页面。

外部资源、嵌入内容和受限浏览器能力本身不是分析阶段的自动拒绝理由；系统应保留可最小渲染的页面，并以“部分兼容”明确告知可能的缺失或不可用行为。单文件模式下相对路径、远程资源和 `blob:` 默认阻断，不会被静默本地化。

## 四、视口确认规则

- 工作台提供电脑 `1440×900`、平板 `768×1024`、手机 `390×844` 三个预设，以及自定义宽高。
- 自定义视口必须为整数，宽度范围 `240–3840`，高度范围 `240–4096`；不符合范围时禁止提交。
- 视口只定义页面的默认展示方式，不修改 HTML 源码，也不把响应式页面转换成固定截图。
- `fixed-canvas` 默认使用 `fixed` 高度；普通 HTML 默认使用 `content` 高度，页面可按内容延伸，`100vh` 等首屏语义仍由页面自身决定。
- 工作台可把当前文件的视口设置应用到全部文件，但每个文件最终提交的 presentation 独立保存。

## 五、导入工作台体验

- 工作台至少展示文件列表、准备/导入状态、页面名称、判型置信度、推荐视口、兼容性提示和实时预览。
- 预览使用独立安全沙箱；安全预览中的运行时错误或加载超时必须显示为不完整/失败状态，但不应仅因预览运行失败阻止用户提交已通过分析的页面。若准备阶段本身失败，则必须先修复或重新选择文件。
- 页面状态必须同时提供文字或辅助技术可读信息，不能只用颜色区分成功、分析中、导入中和失败。
- 用户可以在文件逐项准备完成后继续处理其他文件；批量导入完成后应分别反馈成功数量和失败数量。

## 六、导入后展示规则

- 页面默认展示配置只有一份，持久化在页面 Schema 的 `$demo.presentation` 中；导入、重新打开、预览、截图、发布、使用端和嵌入都以该配置为准。
- 单页工具栏切换设备仅改变临时预览；只有明确执行“设为页面默认”才写回页面配置。
- 画布卡片的拖拽、缩放和排布只改变画布几何，不反向修改页面默认展示配置。
- 修改默认展示配置后，依赖旧 presentation 的截图必须视为失效并重新生成。

## 七、运行时与安全边界

- 无可执行脚本且通过原型门禁的页面创建为 `prototype-html-css` 原型页；包含脚本、事件处理器或 JavaScript URL 的页面创建为 `sandboxed-html` 页面。资源兼容性不改变该决定，不能删除或隐藏源码后伪装成静态成功。
- 隔离页面只能在独立沙箱来源中执行。预览和发布使用短时、不透明的执行凭证；凭证默认有效期为 5 分钟，取消、提交或过期后必须撤销。
- 沙箱仅开放运行所需的脚本能力，并通过 CSP 阻断连接请求；不开放同源访问、表单提交、弹窗、下载、嵌套框架、Worker 或宿主会话通信。父子页面只交换受限的就绪、尺寸和错误状态消息。
- 沙箱降低权限但不承诺绝对断网、CPU/内存硬隔离、零导航尝试或任意脚本行为等价。子 frame 离开受控执行文档时必须明确显示“已离开导入页”并允许重载；运行时错误、超时和上下文关闭必须结束为结构化失败状态并写入脱敏诊断。
- 诊断不得记录执行凭证、草稿标识、HTML 原文或用户代码；发布后的使用端和嵌入不得把沙箱源码作为公开静态资源返回。已获得执行文档的用户仍可能通过浏览器开发工具观察内容，系统不承诺对该用户保密。
