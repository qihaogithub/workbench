# 官网与用户手册 - 需求文档

## 1. 模块定位

官网与用户手册是创作端的公开入口和产品教育层。官网将 OneFlow 定位为面向营销活动业务的 AI 协作平台，优先帮助管理与决策者理解业务背景、当前价值和演进路线，同时让策划、产品、设计、运营设计与开发理解各自的参与方式。用户手册帮助相关角色完成实际使用；项目数据、用户信息和内部实现细节不属于公开内容。

## 2. 业务目标

- 让未登录用户从根路径快速了解 OneFlow，并能进入工作台或用户手册；进入工作台后按需完成登录/注册。
- 让已登录用户从根路径直接回到工作台，减少重复导航。
- 用独立、精选、可版本化的手册覆盖从入门到发布排障的关键路径。
- 明确 OneFlow 创作端与 FlowSite 使用端的职责边界。
- 以减少重复沟通、提前验证和经验复用建立试点价值，引导团队选择范围明确的真实活动验证交付链路。

## 3. 功能需求

### 3.1 官网首页

- 首屏用“真正耗时的，是一个人的想法反复翻译给另一个人”说明跨角色沟通与上下文对齐的业务痛点，展示从活动目标、AI 整理到配置清单、资源要求与真实预览的交付链路示意。
- 正文依次说明业务背景、OneFlow 1.0 当前方案、产品边界、完整工作流、管理价值、现在与未来，最后引导从一个真实活动开始试点。
- 业务背景聚焦能力边界反复解释、资源规范难以验证、经验没有进入下一次；当前方案强调基于团队已沉淀的知识与规范形成可讨论、可预览、可修改的项目结果。
- 产品关系必须明确：活动系统承载业务事实，OneFlow 创作端组织协作交付，FlowSite 使用端消费发布结果。
- 工作流覆盖活动目标、AI 方案与原型、配置资源预览、团队协作、人工验收接入和经验沉淀复用；管理价值聚焦减少协作消耗、问题前移和组织资产积累。
- 路线图区分“当前能力 · OneFlow 1.0”与“未来方向 · 建设中”的 OneFlow 2.0。未来愿景说明 AI 生成页面与素材、活动逻辑与页面外观解耦、系统校验与受控部署，以及人工继续负责目标、标准、审美、例外和最终验收。
- 酒店与装修的比喻仅辅助解释产品关系和演进路线，不作为整页主叙事；不把未来方向包装成当前可用能力。
- 提供“进入工作台”和“阅读用户手册”两个主要入口。
- 提供当前能力、交付工作流和演进路线的页内快速导航。
- 顶部导航将首页、用户手册靠左，进入工作台靠右，不再展示独立登录与开始创作按钮；移动端导航可展开和收起。
- 官网和创作端工作台中的 OneFlow 标识均可点击返回官网首页；已登录用户从工作台点击时仍展示公开官网。
- 延续 Linear 风格的 OLED 黑视觉：使用 `#050505` 主背景、微弱渐变光晕、细边框和克制阴影，避免高饱和大面积渐变。
- 页面支持键盘操作、清晰焦点状态和减少动态效果偏好。

### 3.2 用户手册

- 公开提供手册目录和文章详情，不要求登录。
- 按开始使用、项目创作、配置与预览、协同与版本、模板与知识库、发布与集成、管理员、排障分类展示。
- 支持按标题、描述和标签搜索，并提供推荐阅读路径。
- 文章展示更新时间、版本、目录、上一篇/下一篇和进入工作台入口。
- 文章不存在时明确返回不存在页面；移动端目录可折叠。

### 3.3 路由与访问体验

- `/` 是公开官网；已登录用户访问时直接进入 `/workbench`。
- `/workbench`、项目编辑、CLI 和管理能力需要登录。
- 登录、注册成功后优先返回安全校验后的原始深链接，未指定时进入 `/workbench`。
- 浏览端和嵌入页面保持既有公开访问规则。

## 4. 内容与安全约束

- 手册只收录经过评审的产品使用内容，不直接暴露内部项目文档、用户上传内容或敏感数据。
- 文档中的代码只用于展示，不执行；外链、图片和 Markdown 能力遵循受控白名单。
- 官网和手册不依赖项目列表、会话或需要登录的 API。
- 当前能力文案只描述已实现能力；未来愿景允许展示，但必须与当前能力分区并明确标注未来方向或建设中，不能以现状语气承诺上线、自动生成或无人验收。
- 不采用未经验证的性能、安全或兼容性承诺，不使用宣讲草稿中的效率数字或虚构试点案例；宣讲材料只作为参考，不作为最终产品事实。

## 5. 验收标准

- 匿名访问 `/` 看到官网，已登录访问 `/` 自动进入 `/workbench`。
- 匿名和已登录用户均可阅读 `/manual` 及文章，文章可搜索和前后导航。
- 未登录访问受保护页面时登录后回到原路径，外部重定向值会被拒绝。
- 官网和手册在移动端可用，导航和文章支持键盘与无障碍阅读。
- 首页可快速回答“为何建设、当前解决什么、未来走向哪里”，当前能力与未来承诺可明确区分，页内导航和六步工作流完整。
