# 官网与用户手册路由与内容架构

## 1. 路由边界

官网和手册是无项目上下文的公开页面，工作台则是登录后的项目入口。请求先经过 Proxy：登录用户访问 `/` 或认证页会被送到 `/workbench`；匿名用户访问 `/workbench`、`/demo`、`/cli` 时被送到登录页，并保留原始路径和查询参数。登录后的目标通过 `getSafeRedirectPath` 限制为当前站点的单斜杠路径，拒绝协议相对地址、反斜杠、控制字符和外部协议。

工作台页面仍在服务端调用当前用户和项目管理服务，作为第二道身份校验；通过后复用原有 `HomePage` 客户端组件。因此 Proxy 误放行无效凭证时不会读取项目列表。

| 路径 | 渲染 | 访问边界 |
| --- | --- | --- |
| `/` | Server Component | 公开；登录用户由 Proxy 重定向 |
| `/manual`、`/manual/[slug]` | Server Component | 公开静态内容 |
| `/workbench` | Server + Client | 必须登录 |
| `/demo/[id]/edit`、`/cli` | 现有客户端页面 | 必须登录 |
| `/viewer/*`、`/embed/*` | 现有页面 | 沿用既有公开规则 |

## 2. 内容模型

文章正文以受控 Markdown 文件存放在 `src/content/manual/`，由 TypeScript manifest 绑定元数据。manifest 为每篇文章提供 slug、标题、描述、分类、顺序、更新时间、标签和正文，并通过构建期测试确保 slug 唯一、字段完整和内部链接指向已知文章。

Markdown 渲染器关闭原始 HTML 和自动链接，仅允许站内路径、`https`、`mailto` 以及 `/manual/` 下的本地图片。标题在渲染时生成稳定 ID，文章页面用这些 ID 生成桌面目录和移动折叠目录。代码块只输出文本，不进入执行环境。

## 3. 页面协作

`SiteHeader` 和 `SiteFooter` 提供公开导航；`LandingPage` 只包含静态产品文案和 CSS 视觉效果；`ManualIndex` 在客户端做轻量关键词过滤；`ManualArticle` 在服务端渲染正文并组合目录、前后文章和工作台 CTA。公开组件不调用项目 API、Session API 或浏览器端用户探测。

公开页、工作台通用头部和项目工作台头部统一使用 OneFlow 官网首页地址。地址优先读取 `NEXT_PUBLIC_AUTHOR_SITE_URL`，未配置时使用当前创作端根路径。品牌链接附带 `from=brand` 入口标记，Proxy 只对该品牌入口放行已登录用户访问公开首页；直接访问根路径仍按既有规则进入工作台。独立浏览端使用同名公开配置指向创作端官网，未配置时在本地开发自动回退到 `http://localhost:4200`。

首页使用模块级静态数组承载痛点、当前能力、六步工作流和管理价值；路线图以两个独立、带可访问名称的 article 展示，状态标签与正文共同区分当前和未来。区块通过标题关联提供语义化区域，首屏页内导航分别指向 `current`、`workflow`、`roadmap`，滚动定位为固定顶部导航预留空间。首屏交付示意、工作流有序列表和双栏路线图使用不同视觉层级，不把装饰性示意当成可操作产品界面。

产品叙事和宣传边界统一遵循[官网需求](../官网与用户手册_需求文档.md)，页面 metadata 与共享页脚同步使用相同定位；不从宣讲草稿动态导入内容，也不增加客户端状态、后台接口或新依赖。

## 4. SEO 与缓存

官网、手册目录和文章通过页面 metadata 提供标题与描述；文章使用 `generateStaticParams` 和 `generateMetadata`。`robots.ts` 和 `sitemap.ts` 只列出官网及手册页面，站点基址读取可选的 `NEXT_PUBLIC_AUTHOR_SITE_URL`，本地未配置时使用本地开发地址。工作台、认证页和项目数据不进入 sitemap。

## 5. 样式与可访问性

页面复用现有深色主题和 OneFlow 字标，使用渐变、边框和光晕表达产品气质，不引入大型动画库。动效由 CSS transition 提供，并尊重 `prefers-reduced-motion`。导航菜单、搜索框、文章目录和 CTA 均提供语义元素、键盘焦点和移动端布局。

首页使用适合中文长标题的字号与行高；静态信息卡不附加点击暗示，交互链接和按钮提供指针、hover 与焦点状态。减少动效模式除关闭首屏入场与 transition 外，也移除首页 CTA、示意窗口和工作流卡的 hover 位移。响应式验收覆盖 375、768、1024 和 1440px，组件测试锁定叙事顺序、当前/未来标签、页内锚点、六步工作流及主入口。
