# 页面模块 - 页面架构与路由设计

> 版本：v2.0
> 更新日期：2026-08-13
> 变更说明：补充官网、公开用户手册与工作台独立入口；新建页面默认进入 HTML/CSS 原型页，显式高保真或原型能力不足时才使用 React 页。

---

## 一、技术选型

### 1.1 路由框架

采用 **Next.js 16 App Router** 作为路由管理方案：

| 特性 | 说明 |
|:-----|:-----|
| 文件系统路由 | 基于目录结构自动生成路由 |
| 服务端组件 | 默认使用 Server Components |
| 动态路由 | 支持 `[id]` 动态参数 |
| 路由组 | 支持 `(group)` 分组不影响 URL |

### 1.2 渲染策略

| 页面 | 渲染方式 | 理由 |
|:-----|:---------|:-----|
| 官网首页、用户手册 | 服务端渲染 | 公开静态内容，避免读取项目数据并支持 SEO |
| 工作台 | 服务端首屏 + 客户端交互 | 服务端校验用户后复用 HomePage，客户端负责实时搜索、项目操作 |
| 项目/页面浏览页 | 客户端渲染 | 发布项目和页面的只读预览 |
| Demo 编辑页 | 客户端渲染 | 需要实时编辑、AI 对话 |
| 项目管理页 | 客户端渲染 | 需要实时编辑、版本管理 |
| 嵌入预览页 | 客户端渲染 | 需要 iframe 隔离渲染 |

## 二、路由结构

### 2.1 路由映射表

| 路由 | 文件路径 | 说明 |
|:-----|:---------|:-----|
| `/` | `src/app/page.tsx` | OneFlow 官网首页 |
| `/workbench` | `src/app/workbench/page.tsx` | 当前项目工作台（原项目列表入口） |
| `/manual` | `src/app/manual/page.tsx` | 用户手册目录与搜索 |
| `/manual/[slug]` | `src/app/manual/[slug]/page.tsx` | 用户手册文章 |
| `/demo/[id]/edit` | `src/app/demo/[id]/edit/page.tsx` | Demo 编辑页（独立 Demo 编辑入口） |
| `/demo-test` | `src/app/demo-test/page.tsx` | Demo 测试页 |
| `/embed/[demoId]` | `src/app/embed/[demoId]/page.tsx` | 嵌入预览页 |
| `/viewer/[projectId]` | `src/app/viewer/[projectId]/page.tsx` | 发布项目浏览页 |
| `/viewer/[projectId]/[demoId]` | `src/app/viewer/[projectId]/[demoId]/page.tsx` | 发布页面浏览页 |
| `/login` | `src/app/(auth)/login/page.tsx` | 登录页 |
| `/register` | `src/app/(auth)/register/page.tsx` | 注册页 |

### 2.2 布局结构

```
RootLayout
├── ThemeProvider（主题管理）
├── Header（顶部导航）
└── {children}（页面内容）

(auth) 路由组布局
├── /login
└── /register
```

## 三、数据获取策略

### 3.1 客户端数据获取

使用 **SWR** 进行数据获取和缓存：

| 场景 | Hook | 说明 |
|:-----|:-----|:-----|
| Demo 列表 | `useDemos()` | 获取所有 Demo |
| Demo 详情 | `useDemo(id)` | 获取单个 Demo |
| Session 数据 | `useSession(sessionId)` | 获取会话数据 |

### 3.2 数据流设计

```
用户操作
    │
    ▼
SWR Hook 触发
    │
    ▼
API Client 发送请求
    │
    ▼
Route Handler 处理
    │
    ▼
文件系统 / Agent Service
    │
    ▼
响应返回
    │
    ▼
SWR 更新缓存
    │
    ▼
UI 重新渲染
```

## 四、状态管理

### 4.1 状态分类

| 类型 | 管理方式 | 示例 |
|:-----|:---------|:-----|
| 服务端状态 | SWR | Demo 列表、Session 数据 |
| UI 状态 | React State | 对话框开关、搜索关键词 |
| 表单状态 | RJSF 内置 | 配置表单数据 |

### 4.2 状态流转

```
┌─────────────────────────────────────────────────────────────────┐
│                         首页状态                                 │
│                                                                 │
│  demos (SWR) ─────► Demo 列表数据                               │
│  searchQuery ─────► 搜索关键词                                  │
│  isCreateDialogOpen ─────► 创建对话框状态                       │
│  deleteTarget ─────► 待删除 Demo                                │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                      项目/页面浏览状态                             │
│                                                                 │
│  demo (SWR) ─────► Demo 元数据                                  │
│  session (SWR) ─────► Session 数据                              │
│  code ─────► 组件代码                                           │
│  schema ─────► 配置定义                                         │
│  configData ─────► 配置值                                       │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                      Demo 编辑页状态                             │
│                                                                 │
│  session (SWR) ─────► Session 数据                              │
│  code ─────► 组件代码（可编辑）                                  │
│  schema ─────► 配置定义（可编辑）                                │
│  configData ─────► 配置值                                       │
│  messages ─────► AI 对话历史                                    │
│  isStreaming ─────► AI 响应状态                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 五、页面加载流程

### 5.1 工作台加载

```
1. Proxy 校验登录状态，服务端页面再次确认用户身份
      │
      ▼
2. useDemos() 发起请求
      │
      ▼
3. 复用项目管理服务读取项目列表
      │
      ▼
4. 返回 Demo 列表
      │
      ▼
5. SWR 更新缓存
      │
      ▼
6. 页面渲染 DemoCard 列表
```

### 5.2 项目/页面浏览页加载

```
1. 页面组件挂载，获取路由参数 id
      │
      ▼
2. useDemos() 获取 Demo 名称
      │
      ▼
3. POST /api/sessions 创建临时 Session
      │
      ▼
4. GET /api/sessions/:sessionId/files 获取文件
      │
      ▼
5. 解析 code 和 schema
      │
      ▼
6. getDefaultValues(schema) 提取默认配置
      │
      ▼
7. 渲染预览区和配置面板
      │
      ▼
8. 用户离开时 DELETE /api/sessions/:sessionId
```

### 5.3 Demo 编辑页加载

```
1. 页面组件挂载，获取路由参数 id
      │
      ▼
2. POST /api/sessions 创建编辑 Session
      │
      ▼
3. GET /api/sessions/:sessionId/files 获取文件
      │
      ▼
4. 初始化编辑器内容
      │
      ▼
5. 建立 WebSocket 连接（AI 对话）
      │
      ▼
6. 渲染编辑工作台
```

### 5.4 新建页面默认运行时

创作端新建页面默认创建 HTML/CSS 原型页。页面目录以 `prototype.html`、`prototype.css` 和 `config.schema.json` 作为初始文件，页面元数据标记为 `prototype-html-css`。当用户明确要求高保真 React 实现，或目标效果需要原型页运行时不支持的能力时，才创建 `index.tsx` 并使用高保真 React 页。
