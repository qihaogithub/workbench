# 意见反馈 - 需求文档

> 更新日期：2026-08-05

## 模块定位

意见反馈模块为用户提供提交系统问题、建议和疑问的通道。用户可以手动提交反馈，也可在 AI 对话中由 AI 主动识别系统 bug 并自动生成结构化报告。所有反馈公开可见，便于团队协作处理。

## 功能需求清单

### 1. AI 自动上报系统 Bug

在创作端（workbench 模式）和浏览端（viewer-readonly 模式）的 AI 对话中，当用户描述了系统问题（平台功能故障、工具报错、预览/保存/上传失败、AI 行为异常等），AI 应主动判断是否属于系统 bug 并生成结构化问题报告。报告包含：问题背景、现象、期望行为、复现步骤、AI 判断依据和排查线索。

### 2. 手动提交反馈

在创作端和浏览端的反馈列表页右下角提供悬浮「+」按钮，点击弹出提交表单。表单字段包括：
- 类别（Bug / 建议 / 疑问 / 其他）
- 严重程度（高 / 中 / 低）
- 标题（可选）
- 内容（必填）
- 标签（可选，逗号分隔）
- 姓名（可选，内部系统，方便联系）

### 3. 反馈入口

- 创作端首页 header 右侧提供「反馈」按钮，点击跳转至反馈列表页
- 浏览端首页 header 右侧提供「意见反馈」按钮，点击跳转至反馈列表页

### 4. 反馈列表页

- 按时间倒序展示所有反馈
- 支持按状态、类别、严重程度筛选
- 支持关键词搜索
- Bug 类反馈展开显示完整结构化报告
- 登录用户可修改反馈状态（待处理 / 处理中 / 已完成），状态变更记录历史
- 登录用户可删除反馈

### 5. 存储与共享

反馈数据统一存储于 `data/feedback/feedback.json`，创作端 API 与 Agent 服务共享写入。创作端提供 REST API 供双端页面读写。

## 业务规则

- 反馈列表公开可看，无需登录
- 手动提交反馈以当前用户身份写入（已登录用真实身份，未登录用匿名身份）
- 修改状态和删除操作需登录
- AI 上报的反馈 channel 标记为 `chat`，来源按工具模式推断
- 反馈不会自动查重或撤回
