## 一、模块定位

基础设施模块为整个 Web 前端应用提供底层支撑能力，包括 API 接口规范、错误处理机制、动态编译、Schema 生成等通用服务。

---

## 二、功能描述

### 2.1 API 接口规范

#### 2.1.1 统一响应格式

所有 API 使用统一的响应格式：

**成功响应**：
```json
{
  "success": true,
  "data": { ... }
}
```

**错误响应**：
```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "错误描述",
    "details": { ... }
  }
}
```

### 2.2 动态编译功能

#### 2.2.1 代码编译

**用户视角**：
- 系统应能动态编译 TypeScript/JSX 代码
- 编译结果应可直接在预览区执行

**交互效果**：
- 编译过程应在后台执行
- 编译失败时应展示错误信息

### 2.3 Schema 生成功能

#### 2.3.1 自动提取 Props

**用户视角**：
- 系统应能从组件代码中自动提取 props 定义
- 提取结果应格式化为 JSON Schema

## 三、业务规则与约束

### 3.1 错误码规范

| 错误码 | HTTP 状态码 | 说明 |
|:-------|:------------|:-----|
| DEMO_NOT_FOUND | 404 | Demo 不存在 |
| SESSION_NOT_FOUND | 404 | Session 不存在 |
| PROJECT_NOT_FOUND | 404 | 项目不存在 |
| VERSION_NOT_FOUND | 404 | 版本不存在 |
| DEMO_PAGE_NOT_FOUND | 404 | Demo 页面不存在 |
| FOLDER_NOT_FOUND | 404 | 文件夹不存在 |
| INVALID_REQUEST | 400 | 请求参数无效 |
| VALIDATION_ERROR | 400 | 数据校验失败 |
| UNAUTHORIZED | 401 | 未授权访问 |
| FORBIDDEN | 403 | 无权访问 |
| SESSION_EXPIRED | 410 | Session 已过期 |
| SESSION_NOT_EDITING | 409 | 会话不在编辑状态 |
| SCHEMA_CONFLICT | 409 | Schema 字段命名冲突 |
| FILE_TOO_LARGE | 413 | 文件大小超过限制 |
| FILE_READ_ERROR | 500 | 文件读取失败 |
| FILE_WRITE_ERROR | 500 | 文件写入失败 |
| WORKSPACE_CREATE_ERROR | 500 | 工作空间创建失败 |
| SNAPSHOT_CREATE_ERROR | 500 | 快照创建失败 |
| INTERNAL_ERROR | 500 | 内部服务器错误 |
| UPLOAD_FAILED | 500 | 文件上传失败 |
| COVER_UPLOAD_FAILED | 500 | 封面图上传失败 |
| AGENT_SERVICE_ERROR | 503 | Agent 服务请求失败 |
| FOLDER_DEPTH_EXCEEDED | 400 | 文件夹嵌套不能超过 3 层 |
| CIRCULAR_REFERENCE | 400 | 不能将文件夹移动到自身或其子文件夹中 |
| INVALID_FILE_TYPE | 400 | 不支持的文件类型 |

### 3.2 编译约束

| 约束 | 说明 |
|:-----|:-----|
| 依赖白名单 | 仅允许项目已有的依赖 |
| 代码来源 | 组件代码由 AI 生成，经过系统提示词约束 |

### 3.3 图片入库约束

- 单张图片仍不得超过 10MB。
- 对大于 500KiB 的 JPEG 和静态 PNG，系统可在不改变图片格式和像素尺寸的前提下压缩后入库，以降低存储与传输成本。
- 系统只在压缩结果确实更小时采用压缩版本；不适用格式、动态图片和未获得体积收益的图片保持原样。
- 管理员可对既有图床图片执行统一检查，并仅压缩符合相同规则的存量文件。
