# 闯关活动

如果你举办一场让用户“需完成多个任务，甚至是不同类型的任务”，那么就选它⬇️

# 介绍篇：了解一下

## 一.活动简介

\*\*玩法：“完成多个任务关卡”挑战。\*\*关卡玩法多样，包括：

* **题目关卡：做游戏题（课内40+种题型）**

* **视频关卡：看视频**

* **环节关卡：视频+答题（课内type21环节）**

* **活动关卡：参与拍摄/话题/配音/朗读/PK活动**

* **完读关卡：补学课程**

* **普通关卡：跳转至任意1个链接（例如配置一个抽奖链接，可以去抽奖）**

**分享传播**：**当具有“活动关卡”**，作品提交后可以分享传播至“微信，抖音，小红书”等平台。反之，无“活动关卡”，不存在作品的分享传播

**活动表彰**：**当具有“活动关卡”**，为了激发用户参与，可以在活动结束后，评选“人气奖（微信点赞排名）/自定义奖（常用人工评选优秀作品）/参与奖（参与就能获奖）”，给予“虚拟称号”或“实物”奖励。反之，无“活动关卡”，不存在活动表彰

# 制作篇：如何制作

## 四.协作流程

#### 1.涉及角色：

1场活动最多涉及如下角色，由活动业务方牵头给对应角色提需求：

* 产品 $\color{#0089FF}{@陈宏业}$ ：判断现有功能是否满足业务需求，负责“新功能”开发

* UI $\color{#0089FF}{@祁昊}$ ：解答设计规范问题

* 设计：设计活动所有页面

* 美术：设计页面内要求高较复杂的元素

* 动效：设计页面内所有动效

* 音效：设计页面内背景音乐及动效配音

* 配音：设计页面内文本配音

#### 1.查看作品：

* 所有提交作品会先走“公司统一的风控审核（查杀黄赌毒）”，若违规作品则会直接删除下架，不会展示到后台及C端

#### 3.发布表彰

**仅适用于：有“活动关卡”的闯关活动。若无活动关卡，无需要表彰**

活动结束后，根据活动设置的“表彰”，需手动发布表彰。

* 1个用户：只能获得1个奖项。若同时满足多个奖项标准，则优先获得“发奖顺序高”（后台可设置发奖顺序）的奖项

| 表彰类型     | 解释                                                 | 品牌活动 | 班级活动 | 表彰方式          |
| -------- | -------------------------------------------------- | ---- | ---- | ------------- |
| **参与奖**  | 参与活动获得该称号，最多1个                                     | ☑️   | ☑️   | 系统判断用户参与，系统发放 |
| **排名奖**  | 根据作品点赞数排名获得该称号。需要设置获奖名额，系统根据“点赞数量”自动颁奖。可设置多个       | ☑️   | ☑️   | 系统按点赞数排序，系统发放 |
| **自定义奖** | 作品被活动方手动选为优秀获奖作品获得该称号。需要手动设置获奖名单，自主设置获奖名额和名单。可设置多个 | ☑️   | 不支持  | 运营手动选择获奖名单    |
