OneFlow 使用 Schema 驱动配置表单，让页面结构与实际使用参数保持清晰分工。配置修改后，预览会刷新到当前值。

## 项目级与页面级配置

项目级配置适用于品牌色、站点名称等跨页面值；页面级配置只影响当前页面。优先把可复用的值放在项目级，把内容和布局差异放在页面级。

## Schema 字段

Schema 定义字段类型、标题、默认值和可选范围。填写配置时遵循字段说明；如果字段被标记为必填，保存或发布前需要补齐。

## 检查预览

修改配置后观察预览区是否更新，分别检查宽屏和移动视口。图片、字体和外部资源加载失败时，先确认资源地址和发布环境是否允许访问。

## 运行时差异

固定画板、响应式页面和受限 HTML 页面有不同的尺寸与脚本边界。预览结果是当前运行时的真实表现，不要用另一种运行时的经验推断最终效果。

## 发布前清单

- 必填配置已完成，示例数据已替换。
- 页面路径、标题和分享信息准确。
- 关键视口没有布局溢出或运行时错误。
- 需要外部访问的资源已在目标环境验证。
