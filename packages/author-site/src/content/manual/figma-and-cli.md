OneFlow 同时提供面向设计导入的 Figma 插件入口和面向开发者的 Project Admin CLI。它们操作的是项目资源，不替代工作台中的权限和版本流程。

## Figma 导入

从 Figma 插件选择需要导入的画板或资源，确认目标项目和页面后再提交。导入完成后在工作台检查页面结构、字体、图片和响应式表现。

## CLI 适用场景

CLI 适合脚本化列出项目、读取元数据、导入原型和执行批量管理。先阅读命令帮助和当前项目权限，再在小范围项目上试运行。

## 凭证与权限

CLI 使用当前环境配置的认证方式。不要把 Token 写入仓库、截图或公开日志；共享脚本时通过环境变量注入，并为不同环境使用最小权限。

## 导入后的验收

无论通过 Figma 还是 CLI 导入，都要回到工作台检查页面树、配置 Schema、预览和发布状态。导入只完成数据准备，不代表页面已经通过产品验收。
